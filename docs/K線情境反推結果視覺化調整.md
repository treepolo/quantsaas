# K 線情境反推結果視覺化調整

日期：2026-07-24

## 目的

讓 K 線情境反推的研究結果可正確辨識每一筆已完成測試，並可直接查看所選結果的推導走勢；此調整只讀取既有研究結果，不改變生成、特徵、回測、保存或永久保存規則。

## 顯示規格

1. 二維結果圖為「二十維行為空間的二維投影」，必須有 X／Y 軸名稱、數值刻度與格線。
2. 每筆已完成且可用的評估結果各自繪製一點；點的顏色依結果分類表示。
3. 若兩筆結果在目前選取的兩個特徵上重疊，使用由結果編號決定的小幅固定視覺偏移，使它們仍可個別辨識。偏移只影響呈現，不改變資料座標或研究統計。
4. 滑過或點選點時顯示該筆結果的分類與績效；點選後按需載入並顯示該筆推導出的走勢圖。走勢圖沿用回測圖表的時間區間滑桿、游標同步讀值、實際價格／區間相對與一般／對數刻度，並標示前置歷史行情與正式測試行情。

## 效能界線

二維點位使用單一 Canvas 批次繪製，而非為每個點建立 SVG 或 DOM 節點。命中測試以網格索引縮小候選點範圍；完整 OHLC 僅在使用者點選單一結果後載入。這使切換座標軸與篩選只重繪既有資料，不會重新執行研究或回測。
