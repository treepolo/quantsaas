# 參數穩健區域分析開發指導

> 狀態：完整規格已確認；已納入 M 地形契約、L 共用相對指標契約及 N 成果所有權邊界
>
> 對應大點：J. 參數穩健區域與塔狀分析
>
> 用途：定義如何用一維曲線、二維 heatmap、3D 曲面、多尺度鄰域、多維抽樣與區域幾何，分析核心參數是否具備局部或區域穩健性，並向 M 提出候選前緣與穩健中心。此文件不是三份真源文件，不取代既有穩定系統規格。

## 一、系統定位

本功能用來判斷一組參數是否只是歷史資料上的孤立尖點，或是在附近及同一連通區域仍能維持合理表現。

核心問題：

```text
如果核心參數小幅改變，績效是否仍然穩定？
```

本功能不是完整參數研究工作流，也不修改參數搜尋既有績效評分公式。

它是參數評估點與回測結果的地形、鄰域及區域幾何分析引擎。它可以向 M 輸出穩健中心提案，但不管理研究設定、候選驗證、人工採用或 champion Promote。

## 二、依賴關係

本功能依賴：

```text

docs/研究構想整理/計算任務與快取掃描工具開發指導.md
docs/研究構想整理/長週期風險濾網與過濾模型開發指導.md
```

原因：

- 每個格點都必須透過一致的回測核心產生結果。
- 格點回測結果必須可保存、去重與重用。
- Z 軸與摘要指標需要報酬分析定義。
- 大量掃描必須支援總計算量、進度、取消與快取。
- 若參數帶有長週期濾網，掃描時必須沿用同一濾網設定。

開發順序上，本功能應晚於回測核心、標準化回測結果保存、報酬分析共用模組、計算任務與快取掃描工具。

本功能會被下列 M 系統調用：

```text

```

本文件第八章的期末淨值比、最大回撤殘值比、log 版本與績效回撤綜合指標，也由 L 以同一版本化純計算元件調用：

```text
docs/研究構想整理/擾動行情資料產生器開發指導.md
```

N 通用研究比較不把 J 建立成獨立成果來源。J 的正式輸出由 M `ResearchAnalysisSnapshot` 保存並向 N 提供唯讀比較資料；N 不得直接調用 J、補算地形或建立第二份區域與中心真源。完整 N 邊界見：

```text
docs/研究構想整理/通用研究結果與參數比較工具開發指導.md
```

## 三、分析輸入與兩種入口

J 支援兩種分析入口。

### 3.1 中心點鄰域分析

使用者提供一組中心參數、掃描參數、範圍與步長。系統建立周圍格點，執行回測後分析局部穩健性。

### 3.2 M 評估點集合分析

M 提供：

- 不可變研究設定 ID 與 hash。
- 參數空間 schema。
- 已實際計算的標準化參數向量。
- 每個向量引用的標準化回測結果。
- 每個向量的 J 指標。
- 評估點來源階段與取樣批次。

J 可從這批資料建立全域視圖、局部切片、連通區域與中心提案。

規則：

- 實際回測點、代理預測點與待回測建議點必須明確區分。
- 代理模型只有提案權，沒有證據權；代理點不得用來判定合格區域、邊界距離、候選前緣或中心。
- 缺少必要鄰近點時，J 應回報需要補算的點，不得以無標示插值冒充完整地形。
- 一維與二維圖是高維空間切片，不得被解讀為完整高維結論。

## 四、核心參數精度

核心參數顯示與掃描精度預設為：

```text
小數點後 2 位
```

預設最小有效步長：

```text
0.05
```

不同核心參數未來可有各自步長，但第一版以 `0.05` 作為預設。

## 五、多尺度鄰域

本功能不固定單一鄰域寬度。

預設半徑序列：

```text
1, 2, 3, 5, 8, 13 格
```

使用者可自訂半徑序列。

每一個半徑都必須計算完整穩健性指標，用來觀察：

```text
穩健性如何隨鄰域尺度擴大而衰退
```

半徑以核心參數步長為單位。

例如中心值 `0.50`、步長 `0.05`、半徑 `3` 格：

```text
掃描範圍 = 0.35 到 0.65
```

若掃描範圍超出參數合法邊界，需自動截斷到合法範圍。

## 六、合格條件

鄰域點合格條件固定為兩項同時成立：

```text
總報酬贏過 DCA
最大回撤小於 DCA
```

總報酬與最大回撤應使用同一條回測結果與同一個基準設定。

若該參數或該回測啟用長週期風險濾網，合格條件應使用過濾模型回測結果。

## 七、每個尺度的統計指標

每個半徑尺度都必須計算：

- 鄰域總點數。
- 合格點數。
- 合格比例。
- 合格面積或格點面積比例。
- 鄰域績效平均值。
- 鄰域績效中位數。
- 鄰域績效標準差。
- 中心績效 / 鄰域平均值。
- 中心績效 / 鄰域中位數。

績效預設使用：

```text
log 期末淨值比
```

使用者可切換其他 Z 軸指標。

## 八、Z 軸與評估指標

本功能支援下列 Z 軸：

### 8.1 log 期末淨值比

```text
log 期末淨值比 = ln(策略期末 NAV / DCA 期末 NAV)
```

越大越好。

### 8.2 最大回撤殘值比

```text
最大回撤殘值比 =
(1 - 策略 MaxDD) / (1 - DCA MaxDD)
```

越大越好。

此指標代表最大回撤後，策略保留的資產比例相對 DCA 保留資產比例的倍數。

### 8.3 log 最大回撤殘值比

```text
log 最大回撤殘值比 = ln(最大回撤殘值比)
```

越大越好。

主圖可優先使用 log 版本，因為跑贏與跑輸在尺度上較對稱。

### 8.4 績效回撤綜合指標

```text
績效回撤綜合指標 =
log(策略期末 NAV / DCA 期末 NAV)
×
((1 - 策略 MaxDD) / (1 - DCA MaxDD))
```

越大越好。

此指標不開根號。

### 8.5 合格 / 不合格

合格條件見本文件第六章。

此 Z 軸用於快速辨識穩健區域面積。

## 九、一維分析

使用者可選 1 個核心參數。

中心點入口固定其他核心參數，只沿選定參數依半徑與步長掃描。

M 評估點入口可以選擇一個已被充分評估的切片；切片中其他參數的固定值必須明確顯示，不得把不同固定條件的點混成同一條曲線。

輸出：

- 一維曲線。
- 每個格點的 Z 軸指標。
- 合格 / 不合格標記。
- 中心點標記。
- 多尺度穩健性統計。

所有核心參數都必須可選。

## 十、二維分析

使用者可選 2 個核心參數。

中心點入口固定其他核心參數，掃描兩個選定參數形成格點。

M 評估點入口可以選擇兩個軸及一組其餘參數固定條件。只有同一切片上的實際評估點可以形成同一張 heatmap；缺漏點必須標記或補算。

輸出：

- 2D heatmap。
- 3D 曲面。
- 合格 / 不合格覆蓋層。
- 中心點標記。
- 多尺度穩健性統計。

所有核心參數都必須可作為 X 軸或 Y 軸。

## 十一、疊圖

二維分析必須支援疊圖。

疊圖可包含：

- log 期末淨值比。
- log 最大回撤殘值比。
- 績效回撤綜合指標。
- 合格 / 不合格區域。
- 中心點。

疊圖不得強迫所有圖層一起計算。

若某圖層所需底層回測已存在，切換圖層時不得重跑回測。

若某圖層尚未計算，前端應提示可補算該圖層。

## 十二、批次觀察

本功能可提供批次觀察：

- 所有核心參數的一維曲線。
- 所有兩兩核心參數組合的 heatmap。

批次觀察必須按需啟動，不得頁面載入時自動計算。

批次觀察必須遵守計算任務規則：

- 顯示總計算量。
- 顯示進度。
- 支援取消。
- 使用快取。

## 十三、多維鄰域抽樣

多維鄰域抽樣用來檢查所有核心參數同時小幅偏移時，整體參數是否仍然穩健。

做法：

```text
以中心參數為基準
在指定半徑內對多個核心參數同時抽樣
每個抽樣點都執行回測
統計績效分佈與合格比例
```

多維鄰域不得預設全枚舉，因為計算量會呈指數成長。

例如 6 個核心參數、每個 7 格：

```text
7^6 = 117649 次回測
```

第一版應使用抽樣。

輸出：

- 抽樣點數。
- 合格比例。
- 績效平均值。
- 績效中位數。
- 績效標準差。
- 中心點在抽樣分佈中的位置。
- 績效直方圖。
- 合格 / 不合格比例圖。

## 十四、合格連通區域、候選前緣與中心提案

當 M 提供的實際評估點足以判定區域幾何時，J 必須能：

1. 依合格條件辨識合格點。
2. 依參數空間的合法相鄰關係辨識連通合格區域。
3. 在合格區域內計算績效等高帶、連續平坦度與多尺度穩健性，不增加第二道高績效二元門檻。
4. 計算區域內的方向容錯、軸向內部深度、保證合格方盒半徑與各類邊界截斷狀態。
5. 以彼此分離的績效與穩健性目標建立候選 Pareto 前緣。
6. 從每個不同合格連通區域輸出穩健中心提案。
7. 保存中心提案所依據的評估點、尺度、前緣版本、演算法版本與缺漏狀態。

中心提案的原則：

- 同時考慮績效、區域內部距離與鄰域穩定性，而非只選最高 Z 值。
- 不同合格連通區域可以各自輸出提案。
- 不得把不同一維曲線的各自最佳值拼成一組高維參數。
- 中心提案不是正式候選、challenger 或 champion；必須交由 M 保存、驗證與人工決定。

正式資料不得保存 `is_high_plateau` 一類二元分類。績效等高帶是只讀取既有評估指標的互動視圖；調整等高門檻不得觸發回測，也不得改變合格區域。平坦程度必須以鄰近變化、多尺度衰退與績效離散等連續數值表達。

候選前緣至少使用：

- `log 期末淨值比`，越大越好。
- `log 最大回撤殘值比`，越大越好。
- 未受資料缺口或研究邊界截斷的保證合格方盒半徑，越大越好。
- 多尺度鄰域合格程度與其穩定性，越高越好。
- 鄰域績效離散程度，越低越好。

績效回撤綜合指標可以顯示、排序與疊圖，但不得單獨決定候選前緣或中心。若按需計算項目尚未齊全，前緣必須標記為暫定並列出缺少的目標。

### 14.1 正式離散連通規則

正式連通採軸向相鄰。兩個評估點只有在下列條件全部成立時才建立相鄰邊：

1. 屬於同一份不可變研究設定與相同分析版本。
2. 兩點均合法、已實際回測且合格。
3. 恰好只有一個研究變數不同。
4. 該研究變數在自己的合法離散值序列中剛好相差一個格點索引。
5. 其他研究變數及研究常數一致。
6. 參數 schema、步長與結構版本一致。

不規則合法值以排序後的格點索引判定相鄰，不以原始數值差判定。固定參數不形成維度。若同時改變兩個以上研究變數，不建立對角線邊；但若存在一條逐次只改一個變數一格且沿途全部合格的路徑，兩點仍歸入同一連通分量。

每個分析座標至少具有三態：

```text
合格
不合格
未知或尚未計算
```

未知點既不是合格，也不是不合格。輸出必須分開標示已實測不合格邊界、研究範圍邊界與資料缺口邊界。存在未知缺口時，只能輸出已觀測連通區域或片段，不得宣稱完整區域幾何。

多尺度半徑只限制統計視窗，全部共用同一基礎格點與軸向相鄰圖。稀疏 Sobol 點或高維抽樣不得因距離接近或圖上看似相鄰而被插值連接。

補算點可能造成區域擴張或多區合併。每次分析必須保存評估點集合 hash、合格分類版本、連通演算法版本、結果版本與區域 lineage，不得靜默覆寫舊報告。只有合格分類或連通規則版本改變時才可能造成分裂，且必須另建分析版本。

### 14.2 距離標準化與容錯半徑

每個研究變數先依自己的合法離散值序列轉為格點索引；一個索引單位代表該變數 schema 定義的一個最小有意義步長。固定參數不形成距離維度。

不得直接混用不同參數的原始數值距離，不得以本次使用者研究範圍比例作為主要穩健距離，也不得依本次歷史績效敏感度加權幾何距離。

J 對每個合格點至少輸出：

- 每個研究變數向下與向上的連續合格格數，以及停止原因。
- `axis_failure_depth`：沿軸向合格圖抵達已實測不合格點所需的最少步數；邊界合格點為 `1`。
- `guaranteed_box_radius`：所有研究變數可同時在正負 `r` 格內任意變動，且方盒內每一個合法組合均已實際回測並合格的最大 `r`。

對中心 `p` 與半徑 `r`，方盒包含所有符合下式的合法格點 `q`：

```text
對每個研究變數 i，皆滿足 |g_i(q) - g_i(p)| <= r
```

真正合法邊界不視為失敗，需標記為單側合法容錯。未知點或可擴張研究邊界會使方向容錯、軸向深度或方盒半徑只能回報已知下界，並標記截斷維度、方向與原因。

邊界資料必須分開保存已實測不合格、未知缺口、研究範圍邊界與真正合法邊界。遭未知點或研究邊界截斷的方盒半徑只能形成暫定前緣，且不得只憑下界支配具有完整精確半徑的點。

距離分析只讀取既有評估點。需要補算時由 I 先產生精確 manifest 並顯示計算量、進度、快取、預估時間與儲存量，使用者啟動後才執行。高維資料不足時必須回報下界；一維或二維切片的完整方盒保證不得被擴張解讀成完整高維保證。

### 14.3 穩健中心正式選擇規則

每個合格連通區域分開產生中心。中心不得由最高績效單點或加權總分決定，而是先進入完整穩健候選 Pareto 前緣，再依下列字典式優先規則篩選：

1. 未截斷雙側點、真正合法邊界造成的單側點、未知或研究邊界造成的截斷點分池處理。
2. 未截斷雙側池先最大化 `guaranteed_box_radius`。
3. 同半徑時最大化 `axis_failure_depth`。
4. 仍相同時最小化區域 `medoid_cost`。
5. 仍相同時，只保留在 `log 期末淨值比` 與 `log 最大回撤殘值比` 上互不支配的點。
6. 若仍有多點，全部保存為同級穩健中心，不使用任意總分強迫唯一化。

區域 medoid 成本：

```text
medoid_cost(p) = sum(d_graph(p, q)), q in C
```

其中 `C` 是來源合格連通區域，`d_graph` 是軸向合格圖最短路徑距離。medoid 只在主要容錯距離同分後使用。

中心完整性至少分為：

- 正式雙側中心。
- 正式單側中心。
- 因未知點、研究邊界或缺少按需指標形成的暫定中心。

暫定中心必須列出缺漏 manifest，不能改名為正式中心。補算後另建中心分析版本。每項提案保存來源研究設定、評估點集合 hash、區域版本、前緣版本、中心演算法版本、完整性分級及截斷原因。

多個同級中心可以按完整參數格點索引穩定排序，但該順序只用於 UI 重現，不代表優劣。

### 14.4 角色式候選提案

J 從每個合格連通區域的完整候選前緣向 M 提出：

- 穩健中心。
- `log 期末淨值比`最高的報酬領先點。
- `log 最大回撤殘值比`最高的回撤控制領先點。
- 績效回撤綜合指標最高的綜合領先點。

不使用固定前 `N` 名。相同評估點取得多個角色時只輸出一個提案並附角色集合；不同角色點分別保留；真正同級穩健中心全部保留。完整 Pareto 前緣仍可供使用者手動建立候選。

同分規則：報酬角色先比較回撤殘值再比較容錯；回撤角色先比較期末淨值再比較容錯；綜合角色直接比較容錯。仍同分時保留同級角色點，格點索引只用於穩定顯示。

J 不執行跨研究設定的近似去重。角色提案需攜帶研究設定、評估點、區域、前緣、中心分析與完整性版本；M 依精確評估點身分合併同一點的角色，並負責候選 lineage、人工狀態與後續驗證。

暫定前緣只能提出暫定角色。角色推導共用既有指標，不觸發回測。

### 14.5 代理預測與 J 的邊界

M 已確認代理模型只能提出待回測格點。J 可以顯示獨立且預設關閉的預測地形圖層，但任何正式分析都只能讀取實際 `EvaluationPoint`。

代理預測不得參與：

- 合格或不合格分類。
- 離散連通與區域邊界。
- 方向容錯、軸向深度與保證合格方盒半徑。
- 平坦度、多尺度正式統計與資料完整性判定。
- Pareto 前緣、中心及角色式候選。

代理建議點只有經合法格點對齊、結構驗證、去重、實際回測並形成標準化回測結果後，才能以新的實際評估點進入 J。預測圖層與實測圖層必須使用不同資料來源、圖例與樣式，且開關預測層不得改變任何實測統計。

每個預測點需可追溯到代理執行、來源實測點集合、模型版本、預測值、不確定程度與提案原因；實測後需保留預測誤差。模型品質不足時只能標示為模型探索提案，不得標成推薦。

M 已確認連通、距離、中心、角色式候選、代理權限邊界及預設隨機森林提案機制。代理模型預設關閉，且任何預測都不能改變 J 的正式分析結果。

### 14.6 預設代理提案資料

M 的預設代理工具分別預測 `log 期末淨值比` 與 `log 最大回撤殘值比`，並可能提出保守績效、合格邊界、模型不確定及純 Sobol 覆蓋四類待回測點。

J 只負責將這些點以獨立圖層顯示，至少包含：

- 兩個目標各自的預測值。
- 經驗預測區間。
- 樣本外模型品質狀態。
- 一個點取得的全部提案原因。
- 是否已實際回測，以及預測與實測誤差。

保守績效提案的兩個預測目標必須分開顯示；不得只顯示合成分數。純覆蓋點必須標示為模型無關。任何提案點在形成實際 `EvaluationPoint` 前，都不得進入 J 的合格、連通、距離、前緣、中心或角色運算。

## 十五、計算互動

所有分析項目按需計算。

使用者點哪個項目，才計算哪個項目。

不得要求使用者一次勾選所有項目並等待全部完成。

範例：

```text
一維 Beta 曲線：點了才算
Beta × Gamma heatmap：點了才算
3D 曲面：若 heatmap 格點已算完，只轉換視覺化，不重算
多維鄰域抽樣：點了才算
半徑穩健性衰退曲線：點了才算
```

所有計算必須遵守：

```text
docs/研究構想整理/計算任務與快取掃描工具開發指導.md
```

## 十六、低功耗視覺化

視覺化必須採低功耗設計：

- 預設提供 2D heatmap。
- 3D 曲面可選，但不自動動畫。
- 滑桿拖動不得觸發回測。
- 隱藏分頁停止渲染。
- 未開啟面板不得持續輪詢。
- 大型圖表應避免高頻重繪。

## 十七、完成判準

此功能完成後，至少必須滿足：

- 可選任一核心參數做一維曲線。
- 可選任兩個核心參數做 heatmap 與 3D 曲面。
- 可顯示與切換 Z 軸指標。
- 二維分析可疊圖。
- 可計算多尺度鄰域穩健性。
- 可自訂半徑序列。
- 可執行多維鄰域抽樣。
- 可接收 M 已實際計算的評估點集合。
- 可明確區分實際點、缺漏點與代理估計點。
- 可在公式確認後辨識合格連通區域、候選前緣及穩健中心提案。
- 不會把不同高維切片錯誤合併。
- 中心提案可追溯到來源評估點、尺度與演算法版本。
- 第八章相對指標可由 J、M 與 L 共用同一純函數及版本，公式不分叉。
- 所有分析按需計算。
- 所有計算顯示總量、進度並可取消。
- 掃描結果可快取與重用。

## 十八、實作與驗收紀錄

P08 / J 已於 2026-07-16 完成，正式實作採用以下版本化邊界：

- 純分析公式與參數空間：`p08-analysis-v1`。
- 評估點執行輸入：`p08-point-execution-v2`。
- P05 executor：`p08-point-executor-v2`。
- 評估點結果：`p08-point-result-v2`。
- 研究設定、評估點及分析快照均保存版本、canonical hash 與來源引用；資料表由 GORM model 與 AutoMigrate 管理，未建立 SQL migration。

點執行 v2 的快取身分只包含真正影響回測的不可變輸入，不包含研究名稱、座標維度或顯示設定。研究完成同步時，座標與參數由該研究已保存的 parameter space 及任務 item key 重建，因此相同實際參數即使位於不同 1D／2D／多維研究，仍能安全重用同一 P05 結果，而不會遺失各研究自己的座標。

正式驗收包含：

- 純函數測試：合法格點、固定參數、多維抽樣、相對指標、合格條件、連通區域、未知邊界、容錯距離、多尺度、Pareto、medoid、中心與角色提案。
- PostgreSQL 整合測試：不可變研究、顯式啟動、進度、分析快照，以及 1D 三點與 2D 九點之間三個重疊點命中快取、六個新算點的精確對應。
- 備份復原：增量備份 v6 可完整還原研究、評估點、分析快照、任務、快取與標準化回測引用圖並核對完整性。
- 前端與瀏覽器：一維曲線、二維 heatmap、同資料 3D、Z 軸與疊圖切換、正式分析、多維統計、無動畫、背景停止輪詢、舊預覽失效及窄螢幕無水平溢位。
