# 共用行情與參數選擇器開發計畫

狀態：全頁盤點與第二階段擴充中（2026-07-24）。

文件定位：本文件是降低大量行情與參數選取成本的獨立介面改進計畫；不取代既有三份穩定系統真源，也不改變行情版本、資料血緣、權限、回測或策略語義。

## 目標

將散落於各頁、會累積至數十或數百筆的原生下拉選單，逐步替換為共用選擇器。使用者可用名稱、代號、週期或資料類別快速找到資料，並優先看到常用選項。

## 第一階段：行情選擇器

- 適用於行情圖表與回測頁。
- 支援文字搜尋、資料類別、週期篩選、最近使用及釘選。
- 回測模式只顯示既有契約已允許回測的來源。
- 每筆結果顯示名稱、代號、週期、使用者可見分類、資料範圍與根數；不把內容雜湊、內部 artifact kind 或策略內部代號顯示給使用者。
- 最近使用與釘選是瀏覽器內的個人介面偏好；實際送入回測的版本 ID、內容雜湊與資格仍以既有 API 與後端檢查為準。
- 停用、封存、無權限或失效來源若已被舊頁面選取，必須顯示可理解的不可用提示，不得悄悄換成另一筆資料。

## 後續：參數選擇器

沿用相同互動骨架，但依既有資料契約篩選適用標的、週期、執行假設及角色（已採用、候選、歷史）。參數來源與行情來源維持分開，避免混用不同研究背景的資料。第一輪已套用到「參數獲利範圍研究」、「參數穩健性」與「預測與動態參數」的來源參數欄位。

## 全頁盤點規則

逐頁檢查所有原生選取欄位：只要選項來自可累積的資料、商品、行情版本、參數、研究、任務或群組清單，就改用可搜尋選擇器；固定且少量的研究模式、執行假設、圖表刻度、指標或週期，則保留原生選單，避免把兩三個選項也改成不必要的彈窗。

行情圖表的「副走勢」是多選情境：改為搜尋式多選面板，主要行情固定保留，其他最多三組；已選副走勢以可直接移除的標籤呈現，不能再使用難以搜尋的長核取清單。

## 表單版面規則

搜尋式選擇器在一般表單中必須與既有輸入框及原生選單同高、同一行摘要、同一標籤間距；完整資料範圍、類別與其他次要資訊只在展開面板顯示。只有行情圖表的主要行情可採較高的兩行摘要，因為該區需要直接顯示資料範圍。不得讓搜尋式欄位改變既有表單網格的行高或排列節奏。

## 非目標

- 不修改研究行情分類、不可變版本、資料血緣、內容雜湊或資料表。
- 不讓 UI 偏好資料取代後端權限與可回測驗證。
- 不在策略核心新增任何 I/O、網路、時間或資料庫依賴。

## 驗收

1. 回測與行情圖表可搜尋並選取原始、參考與各類研究行情；回測不列出不可回測的來源。
2. 釘選與最近使用於同一瀏覽器保留，且不影響資料本身排序或其他使用者。
3. 切換後既有日期、圖表與回測請求維持原本同步規則。
4. 前端正式建置通過；登入後實際操作驗收搜尋、篩選、釘選、最近使用與回測選擇。
