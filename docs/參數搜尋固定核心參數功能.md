# 參數搜尋固定核心參數功能

## 文件定位

本文件是參數搜尋器新增功能的開發規格與驗收紀錄，不取代 `docs/系統總體拓撲結構.md`、`docs/策略數學引擎.md`、`docs/進化計算引擎.md` 三份既有穩定系統真源文件。

## 需求

使用者在參數搜尋器建立任務時，可以先選擇一組既有參數作為基準參數，再勾選要固定的核心參數。搜尋任務會以該基準參數作為種子之一，且所有候選基因在評估與保存前，都會把被勾選的核心參數覆寫回基準參數值，只讓未勾選的核心參數參與演化。

## 範圍

- 參數搜尋器 UI 可選擇同一策略、標的、資料源、週期與執行模式下的既有參數。
- UI 可勾選一個或多個核心參數作為固定欄位。
- 後端驗證基準參數必須與本次搜尋 scope 相同。
- 固定欄位清單與基準參數 ID 會寫入任務設定與產出參數的搜尋設定。
- GA 引擎在 sample、mutate、crossover、elite decode、結果 encode 前都套用同一套固定欄位正規化。

## 不在本次範圍

- 不改策略核心公式。
- 不新增 SQL migration。
- 不新增交易所憑證、外部 I/O、網路、時間或資料庫依賴到策略核心。
- 不把內部策略診斷代號暴露成使用者可見 UI 文案。

## 驗收條件

- 未選基準參數時，既有參數搜尋流程維持原行為。
- 選基準參數但未勾選固定欄位時，只把基準參數加入初始族群，搜尋仍可演化全部允許欄位。
- 選基準參數並勾選固定欄位時，所有候選與最終保存參數的固定欄位等於基準參數值。
- 跨標的、跨資料源、跨週期或跨執行模式的基準參數會被後端拒絕。
- 任務與參數庫可回看本次固定欄位清單與基準參數 ID。
