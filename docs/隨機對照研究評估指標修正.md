# 隨機對照研究評估指標修正

**文件定位：** 已確認的 UI 與評估結果呈現規格。  
**確認狀態：** 已由使用者確認，可實作。  
**是否為 MVP：** 否，本次一次到位。

## 適用範圍

適用於「隨機參數與無意義規則對照」的分析快照，不改變策略核心、回測成交假設、資料庫結構或既有不可變快照資料。

## 評估對象與對照組

- 使用者可見名稱一律使用「評估對象」，不使用「基準」。
- 評估對象分別與同結構隨機參數組、曝險順序打亂組比較。
- 各比較都應顯示評估對象的報酬、最大回撤與 Sortino 百分位；無法計算 Sortino 時顯示無資料，不以其他值替代。
- 分析快照底部的兩個比較結論標籤，也必須各自列出報酬、最大回撤與 Sortino 百分位，並沿用既有結論標籤的顏色與規則。

## 任務設定摘要

在「任務與階段」的已選任務下方顯示該任務凍結的研究規則與設定，包括資料與回測條件、隨機參數／曝險打亂的 seed 與樣本數，以及四種規則對照。摘要必須由後端 task canonical 設定提供，不得由前端推測或使用當前表單值。

## 百分位與回撤語義

- 百分位的儲存與 API 值域為 `0` 至 `100`，UI 直接加上 `%`，不得再乘以 100。
- 報酬與 Sortino 採「愈高愈好」的經驗中位排名百分位。
- 最大回撤採評估對象的原始最大回撤率，直接與同一對照組各成員的原始最大回撤率比較；不取 log、不做殘餘比率或其他轉換。
- 回撤採「愈低愈好」排名，故較小的最大回撤會得到較高百分位。
- 三項百分位儲存格採固定連續色階：`0%` 為紅 `rgb(248,113,113)`、`50%` 為黃 `rgb(250,204,21)`、`100%` 為青綠 `rgb(45,212,191)`；中間值以分段線性插值產生。分布分位數與樣本數不套用此色階。
