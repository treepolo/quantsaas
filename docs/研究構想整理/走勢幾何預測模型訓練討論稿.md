# 走勢幾何預測模型訓練討論稿

> 文件定位：研究討論稿與開發計畫收集處，不是既有穩定系統真源，也不批准程式實作。
>
> 狀態：暫停待討論；僅記錄截至 2026-07-25 已確認的方向。

## 一、目的與獨立邊界

建立一條新的「走勢幾何預測模型」訓練方案，用過去窗口的價格外框形狀與趨勢，預測未來窗口的外框面積與趨勢可能性。

本方案是新的模型路線，不取代、不修改也不影響：

- 既有可解釋波動特徵模型。
- 既有其他預測模型路線。
- 既有六個 OHLC 波動指標的計算、使用與研究結果。
- 動態適應參數機制的狀態、政策、參數搜尋、回測或採用語義。

新模型路線在使用者可見的模型路線選單中排在最上方。

## 二、已確認的觀測資料

每個商品、每個資料週期分別訓練模型；不把不同商品或不同週期混入同一模型。

對固定觀察窗口內的每日 K 線：

1. 每日 x 座標為其窗口序號，間隔固定為 1。
2. 每日提供 `(x, High)` 與 `(x, Low)` 兩個點。
3. 以全部高低點形成最外層、不交叉的凸包邊界多邊形。
4. 三點或以上共線時，邊界頂點清單不保留共線的中間點。
5. 以邊界多邊形的面積作為該窗口的「走勢覆蓋面積」。
6. 以窗口內全部收盤價與 K 線序號求出最佳回歸直線；其原始斜率作為該窗口的「趨勢」。

凸包可使用線性或近線性演算法計算，不需要枚舉全部兩點連線。

走勢覆蓋面積刻意只保留足以改變外框的必要波動資訊；外框內、不改變面積的折返波動不是本方案欲預測的資訊。

## 三、已確認的訓練問題

每個時點建立一筆因果訓練資料：

| 角色 | 資料 |
|---|---|
| 輸入 | 截至該時點的觀察窗口走勢覆蓋面積與趨勢斜率 |
| 訓練目標 | 之後固定預測窗口的走勢覆蓋面積與趨勢斜率 |

模型輸出不是未來逐根 K 線，也不是單一未來價格線；它輸出未來窗口「走勢覆蓋面積、趨勢斜率」組合的聯合機率分布。

本方案不使用六個波動指標作為訓練輸入，不以它們建立狀態，也不與既有動態政策混用。

面積、趨勢與模型輸出保持原始價格尺度；本方案不新增標準化、相對中位數、正常活動尺度或其他轉換。

## 四、訓練與動態參數搜尋解耦

目前預測模型訓練與動態參數搜尋屬於連續工作流。本輪新增的產品方向是：兩者必須可分開、獨立啟動與完成。

已確認行為：

- 模型訓練可獨立建立、執行、驗證、保存與查看結果，不自動開始動態參數搜尋。
- 動態參數搜尋可獨立建立與執行；如其設定需要預測模型，使用者選取一個已完成且相容的凍結模型 artifact 作為輸入，不重新訓練模型。
- 同一頁呈現兩類工作沒有問題，可採左右兩區或其他清楚布局；畫面共頁不代表任務生命週期綁定。
- 訓練任務與搜尋任務必須各自有設定版本、進度、取消、失敗、完成、結果與快取生命週期。
- 既有已保存的模型、預測、動態政策、搜尋與回測結果必須保持可讀與可重現。

這是架構與操作流程改造；尚未確認其資料模型、相容規則、舊任務遷移與 UI 細節，不得實作。

## 五、明確不做

- 不以本方案取代既有模型路線。
- 不改寫既有六項波動指標的語義。
- 不讓新模型直接輸出持倉、交易指令、狀態或動態參數。
- 不自行增加標準化、比例、門檻、權重、外部市場資料或其他特徵。
- 不因模型訓練完成而自動啟動動態參數搜尋。

## 六、待討論與待確認

以下尚未完成規格，不得進入實作：

1. 觀察窗口與預測窗口的可設定方式，以及是否允許多組候選窗口。
2. 「最佳回歸直線」的精確公式、資料不足與無效資料處理。
3. 聯合機率分布的模型家族、訓練 loss、校準方式與評估指標。
4. 時間切分、walk-forward、資料洩漏防護與盲測規則。
5. 新模型 artifact、預測結果、版本與快取的保存契約。
6. 新模型是否以及如何可被既有動態參數搜尋引用；此引用不得改變既有 K 的狀態或政策語義。
7. 訓練與動態參數搜尋解耦後的既有任務相容、遷移與回歸驗證範圍。
