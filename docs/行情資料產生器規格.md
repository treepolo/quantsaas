# 行情資料產生器規格

## 文件定位

本文件記錄行情資料產生器的新功能規格。它不是三份真源文件的一部分；功能穩定前不得把本文件內容合併回 `docs/系統總體拓撲結構.md`、`docs/策略數學引擎.md` 或 `docs/進化計算引擎.md`。

本文件只定義目前既有的每日 n 倍做多模式。已確認但尚待開發的「局部行情擾動」與「K 線片段重組」保持為獨立研究功能，完整實作契約見：

```text
docs/研究構想整理/擾動行情資料產生器開發指導.md
docs/研究構想整理/K線片段重組行情產生器開發指導.md
```

三種模式共用行情資料產生器頁面與研究商品儲存入口，但不得混用公式、覆蓋規則或資料血緣。每日 n 倍做多仍依本文件採既有覆蓋規則；L 與 E 依各自文件使用不可變版本，不得為了共用頁面而改回覆蓋。

## 功能目標

行情資料產生器使用已匯入的真實行情資料作為母資料，依使用者選定的資料區間與調整方法產生新的獨立研究商品資料。產生後的新資料保存為一般研究商品，可被研究資料集頁面選用。

目前只提供一種調整方法：每日 n 倍做多。`n` 由使用者輸入，必須為大於 0 的有限數值。

## 輸入

- 母研究商品。
- 母資料週期。
- 起始日期與結束日期。
- 倍率 `n`。
- 新研究商品代號、顯示名稱與資料代號。

## 資料來源與儲存

- 新資料使用內部資料來源 `generated`。
- 新資料會建立或更新一筆獨立研究商品。
- 產生時會覆蓋同一新研究商品、同一資料代號、同一週期下的既有 K 線，避免舊區間殘留。
- 新資料不呼叫外部行情 API，不帶入交易所憑證，不改動策略核心。

## 計算規則

母資料依 `open_time` 遞增排序。子資料第一筆前一日收盤價視為 `10000`。

若選定區間第一筆之前存在母資料前一筆 K 線：

- 子資料當日開盤價 = 子資料前一日收盤價 x `(1 + n x (母資料當日開盤價 / 母資料前一日收盤價 - 1))`
- 子資料當日收盤價 = 子資料前一日收盤價 x `(1 + n x (母資料當日收盤價 / 母資料前一日收盤價 - 1))`

若選定區間第一筆之前不存在母資料前一筆 K 線：

- 第一筆用母資料當日開盤價作為基準。
- 子資料第一筆開盤價 = `10000`
- 子資料第一筆收盤價 = `10000 x (1 + n x (母資料第一筆收盤價 / 母資料第一筆開盤價 - 1))`

從第二筆開始，一律使用母資料前一筆收盤價與子資料前一筆收盤價延續計算。

## OHLC 欄位

使用者指定的新資料必須具有開盤價與收盤價。為符合既有 K 線資料表欄位，新資料的最高價與最低價以產生後的開盤價、收盤價補齊：

- 最高價 = `max(子資料開盤價, 子資料收盤價)`
- 最低價 = `min(子資料開盤價, 子資料收盤價)`
- 成交量 = `0`

若任一產生後開盤價或收盤價小於等於 `0`，本次產生失敗並不寫入資料，使用者需降低倍率或縮短區間。
