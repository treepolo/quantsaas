# 行情圖表與研究行情整合開發計畫

狀態：使用者已確認，2026-07-19 納入正式開發。

本文件是行情查看、研究行情跨頁整合與無參數回測的獨立開發真源，不修改既有三份穩定系統真源文件。本輪不是骨架或 MVP；完成條件包含後端授權與不可變版本檢查、前端完整操作、文件同步、測試、重建與實際頁面驗收。

## 一、目的

1. 在「行情資料」直接查看原始行情、參考指標與研究生成行情。
2. 同一圖表最多疊合四組資料，可切換實際價格／起點對齊 100，以及一般／對數刻度。
3. 可切換收盤價走勢與 K 線；K 線固定綠漲紅跌。
4. 局部擾動、片段重組與倍數產生行情可在「行情資料」查看，也可在「回測」選用。
5. 各類資料必須分組顯示，不得混進原始行情或參考指標分類。
6. 回測可選「不使用策略參數」，但資金、每月投入與交易成本仍沿用既有欄位及既有回測資金語義，不新增另一套定投設定。

## 二、行情分類與使用者可見名稱

| 內部 artifact kind | 使用者可見分類 | 可看圖 | 可回測 |
|---|---|---:|---:|
| `source_snapshot` | 原始／匯入行情 | 是 | 是 |
| `reference_indicator` | 參考指標 | 是 | 否 |
| `daily_leverage` | 倍數產生行情 | 是 | 是 |
| `segment_recomposition` | 片段重組行情 | 是 | 是 |
| `local_perturbation` | 局部擾動行情 | 是 | 是 |
| 其他已發布研究版本 | 其他研究行情 | 是 | 依版本契約 |

分類只影響呈現與合法用途，不改寫資料版本、來源血緣或內容雜湊。

## 三、後端契約

### 3.1 行情來源清單

`GET /market-data/charts/sources`

回傳使用者有權查看的來源描述，包括商品、週期、資料範圍、K 線根數、分類、版本 ID、內容雜湊、完整性狀態與是否可回測。

- 原始／匯入行情由目前 K 線資料範圍形成。
- 研究行情只列出目前使用者擁有、已完成、完整性有效、已發布且未封存的不可變版本。
- 內部來源快照不得重複出現在一般研究行情清單。
- 原始行情範圍必須以單次分組彙總查詢取得，不得逐商品、逐週期發出大量計數查詢。
- 某個研究版本的輸出商品已停用時，只略過該版本，不得使整份行情來源清單失敗。
- 前端載入研究行情清單期間或該請求失敗時，必須先用既有商品清單提供原始行情選項，不得顯示成沒有商品的空選單；研究行情恢復後再補入各自分類。

### 3.2 行情圖表資料

`GET /market-data/charts/bars`

- 原始來源以 `instrument_id + interval + 日期區間` 讀取。
- 研究行情以 `version_id + interval + 日期區間` 讀取，並驗證擁有者、發布狀態與完整性。
- 單次最多 5,000 根；超大區間由介面明確提示，不得靜默假裝已回傳全部資料。

### 3.3 回測研究行情

不可變研究行情送入既有回測時，請求必須同時帶入 `market_data_version_id` 與 `market_data_content_hash`。後端必須核對版本輸出商品、週期、內容雜湊、發布狀態及完整性；不得只靠前端選項信任版本。

### 3.4 不使用策略參數

回測來源 `baseline` 的使用者可見名稱固定為「不使用策略參數」。

- 不讀取 champion、candidate、custom JSON 或其他策略參數。
- 使用既有初始資金、每月投入、費率、滑價與執行時點欄位。
- 不新增第二套「定投模式」或「買入持有模式」設定。
- 不套用策略專屬長週期風險濾網。
- 結果必須標示為無參數結果，不得冒充策略績效或匯出成策略參數來源。

## 四、圖表操作

1. 「主要行情」決定日期預設及區間滑桿。
2. 疊合資料最多四組；各資料以固定顏色辨識。
3. 「收盤價走勢」顯示各組收盤價折線。
4. 「K 線」顯示所有已選資料的 OHLC；所有資料固定綠漲紅跌。主要行情以完整不透明度顯示；其他疊合資料以較低透明度及綠／紅色階的明度、飽和度差異區分，避免多組 K 線互相遮蔽或難以分辨。
5. 「起點對齊 100」以目前可見區間第一筆有效收盤價換算，不改寫原始資料。
6. 「對數刻度」只在所有顯示值均為正數時可用。
7. 區間滑桿、同步游標、日期與 OHLC 提示必須跟既有回測圖表操作一致。

## 五、日期預設

所有選定行情資料的起始日期，預設為該來源實際第一日；結束日期預設為實際最新日。使用者手動修改後可保留修改，但切換資料來源時必須重新帶入新來源範圍。

## 六、驗收

1. 行情資料頁能看原始、參考、倍數、重組、擾動行情，分類正確。
2. K 線綠漲紅跌；切換收盤價走勢／K 線時，所有已疊合資料同步切換為相同呈現方式；對齊 100、對數刻度、日期與滑桿皆可操作。
3. 局部擾動已發布版本可直接送入回測，內容雜湊不符時後端拒絕。
4. 「不使用策略參數」不需要任何參數庫紀錄也能執行，且沿用既有每月投入欄位。
5. 無參數結果不顯示策略訊號權重、參數門檻或建立行情樣貌反推入口。
6. Go 全專案測試、前端正式建置、Docker 重建與登入後瀏覽器操作驗收通過。
7. 停用任一已發布版本的輸出商品後，行情資料與回測的其他商品仍可選；來源 API 不因單筆停用版本整體失敗。
