# 雲端備份與還原使用說明

這份文件對應備援方案第三層：完整系統資料的備份與還原。目標是電腦故障後，能用 GitHub 專案加上備份檔還原 QuantSaaS 的資料、參數庫、採用參數與行情資料。

## 備份策略

第一版保留三種備份：

| 類型 | 檔案位置 | 用途 |
|---|---|---|
| 每日增量 | `backups/incremental/*.zip.enc` | 備份全量之後新增或變更的研究資料 |
| 每週全量 | `backups/full/weekly-full-*.zip.enc` | PostgreSQL 完整備份，作為可靠還原錨點 |
| 手動全量 | `backups/full/manual-full-*.zip.enc` | 在你想保險時手動做完整備份 |

備份會先壓縮再加密。未加密的 `.zip` 會在腳本完成後刪除。

## 備份內容

全量備份包含：

- PostgreSQL plain SQL dump
- `docker-compose.yml`
- `config.yaml` 設定模板
- 備份 manifest

每日增量包含：

- 商品清單
- K 線資料
- 資料集 metadata
- 收盤前快照資料
- 參數庫
- 參數探索紀錄
- 演化任務
- 回測紀錄

不備份：

- Docker image
- `node_modules`
- 暫存檔
- 交易所 API 憑證
- `config.agent.yaml`

## 快速使用

在 `D:\量化交易` 可以直接雙擊：

| 檔案 | 用途 |
|---|---|
| `建立每日增量備份.bat` | 建立一次增量備份 |
| `建立每週全量備份.bat` | 建立一次週全量備份 |
| `建立手動全量備份.bat` | 建立一次手動全量備份 |
| `設定自動備份排程.bat` | 建立 Windows 排程，每天增量、每週全量 |
| `還原全量備份.bat` | 從全量備份還原資料庫 |
| `套用增量備份.bat` | 在全量還原後套用每日增量 |

## 自動備份排程

雙擊：

```text
設定自動備份排程.bat
```

會建立：

- 每天 08:10：每日增量備份
- 每週日 09:10：每週全量備份

排程執行時不能互動輸入密碼，所以若要讓排程自動成功，請先設定 Windows 使用者環境變數：

```text
QUANTSAAS_BACKUP_PASSWORD
```

這是備份加密密碼。請自己保存好；忘記後無法解開備份。

## 上傳到雲端

第一版支援 rclone，但不強迫你現在立刻設定。

如果要自動上傳到 Google Drive、OneDrive、Dropbox 等雲端：

1. 安裝並設定 rclone。
2. 設定 Windows 使用者環境變數：

```text
QUANTSAAS_BACKUP_REMOTE
```

範例：

```text
gdrive:QuantSaaSBackups
onedrive:QuantSaaSBackups
dropbox:QuantSaaSBackups
```

設定後，排程與腳本使用 `-Upload` 時會把 `.zip.enc` 加密備份上傳到該目的地。未設定時，腳本只保留本機 `backups/`。

## 還原流程

新電腦或空資料庫還原時：

1. 安裝 Git、Docker Desktop。
2. 從 GitHub clone 專案。
3. 下載最近一次每週或手動全量備份。
4. 雙擊 `還原全量備份.bat`，貼上該 `.zip.enc` 路徑。
5. 依時間順序，對全量備份之後的每日增量備份逐一雙擊 `套用增量備份.bat`。
6. 啟動 Docker compose，登入系統檢查行情資料、商品清單、參數庫與採用參數狀態。

注意：全量還原會清空目前 PostgreSQL 的 `public` schema，再匯入備份。請只在新環境、空資料庫，或你明確要覆蓋目前資料時使用。

## 指令版

建立每日增量：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\backup\incremental_backup.ps1
```

建立每週全量：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\backup\full_backup.ps1 -Kind weekly-full
```

建立手動全量：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\backup\full_backup.ps1 -Kind manual-full
```

還原全量：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\backup\restore_full.ps1 -Archive "D:\path\weekly-full-xxx.zip.enc" -ConfirmRestore
```

套用增量：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\backup\restore_incremental.ps1 -Archive "D:\path\daily-incremental-xxx.zip.enc"
```

## 驗收方式

最基本驗收：

1. 跑一次 `建立手動全量備份.bat`，確認產生 `backups/full/manual-full-*.zip.enc`。
2. 跑一次 `建立每日增量備份.bat`，確認產生 `backups/incremental/daily-incremental-*.zip.enc`。
3. 在測試用資料庫還原全量，再套用增量。
4. 還原後檢查市場資料、商品排序、參數庫、採用參數是否存在。

若只是保險使用，平常至少確認 `.zip.enc` 有產生，且雲端同步成功。
