# 動態適應參數機制開發指導

> 狀態：規格已確認，已同步 N 唯讀比較契約，待排程開發
>
> 對應大點：K. 動態適應參數機制
>
> 用途：定義以因果市場預測、結構狀態與動態政策產生每日有效核心參數的完整研究機制。此文件不是三份真源文件，不取代既有穩定系統規格，也不代表已核准直接修改正式策略。

## 一、系統定位

本功能要研究的不是「替不同市場狀態人工填幾組參數」，而是：

```text
從截至當日可取得的行情資料
→ 預測未來方向、上下行空間與路徑波動
→ 形成可解釋且具有遲滯的市場狀態
→ 計算當日有效核心參數
→ 交給既有策略核心計算目標持倉
```

研究者負責決定可解釋的特徵、模型家族、規則與限制；電腦只在這些限制內搜尋具體數值與組合。

本功能的核心原則：

- 預測模型與參數績效搜尋分離。
- 預測模型不得使用策略損益訓練、驗證或選擇狀態門檻。
- 預測模型不得直接輸出持倉或交易命令。
- 動態機制只產生每日有效核心參數。
- 既有純策略核心仍負責根據有效參數計算目標持倉。
- 參數搜尋既有績效評分公式不因 K 而修改。

## 二、明確排除

K 不包含下列機制：

- 相似歷史情境搜尋。
- KNN、最近鄰、DTW、型態範本、motif 或案例檢索。
- 依執行當日行情尋找「歷史上最像的日期」。
- 相似歷史情境的加權經驗分佈。
- 自動比較並選擇特徵模型或序列模型冠軍。
- 模型平均、ensemble 或兩條模型路線的動態切換。
- 預測模型直接繞過既有策略核心輸出倉位。
- 以策略 P&L 訓練或驗證市場預測模型。
- 日報酬標準差作為本輪波動特徵。
- 三次以上動態函數或不同預測輸入的交叉乘積。
- Energy Score、Variogram Score 作為本輪已確認選模套件。
- 寫死 2010 年前訓練、2010 年後測試的特殊流程。
- 重做既有合成三倍費半行情功能。

原始構想中的「相對 S&P 500 波動率」或其他外部市場指標，尚未形成已確認的 FeatureSpec、時間可用性、缺值與跨商品公式，因此不是本文件已確認的 K 輸入。若後續要加入，必須依 `docs/多資產與宏觀指標研究升級計畫.md` 另行討論，不得由實作者自行補入。

過去行情可以用來訓練固定模型參數，但執行時的預測必須是：

```text
F_hat(H,t) = f_theta(X_<=t)
```

不得在執行時檢索歷史案例。

## 四、與既有穩定系統的邊界

### 4.1 不取代既有四狀態市場層

三份穩定真源目前定義：

- `BULL_TREND`
- `BEAR_TREND`
- `QUIET`
- `SHOCK`

K 的六種預測結構狀態是獨立研究層，不得靜默取代、改名或重解釋既有四狀態層。

若未來要讓 K 正式取代或改寫既有市場狀態感知層，必須在 K 完整實作、驗證及使用者核准後，再另行更新三份真源文件。

### 4.2 策略核心保持純計算

模型載入、資料讀取、特徵建構、預測與狀態更新都在 Research / SaaS / Lab 外圈完成。

策略核心不得新增：

- 資料庫依賴。
- 檔案或模型檔讀取。
- 網路呼叫。
- 系統時間呼叫。
- 不可控隨機。
- 回測專用分支。

回測與正式研究判讀仍須使用同一個 `Step()` 契約與同一個 `execution_mode`。

## 五、預測期與目標

系統分別建立：

- 1 個交易日預測。
- 20 個交易日預測。

兩個預測期不得混成同一目標。每個預測期 H 都要分別產生三類輸出：

1. 終點收盤上漲機率。
2. 完整未來上下行空間聯合分佈。
3. 未來路徑波動輸出。

### 5.1 終點方向標籤

```text
Y_direction(H,t) = 1(Close[t+H] > Close[t])
```

實際標籤只有上漲與非上漲兩類。「不確定」只能是模型預測時的拒答狀態，不是第三種實際標籤。

### 5.2 完整上下行空間

以上一個決策時點已知的當日收盤價 `Close[t]` 為錨點：

```text
U(H,t) = max(0, max(ln(High[t+h] / Close[t])), h=1..H)
D(H,t) = max(0, max(ln(Close[t] / Low[t+h])),  h=1..H)
```

其中：

- `U` 是未來 H 日完整路徑中可達的最大上行 log 空間。
- `D` 是未來 H 日完整路徑中可達的最大下行 log 空間。
- 兩者都以 0 為下限。
- 不能只用第 H 日收盤價替代完整未來高低點路徑。

模型要學習：

```text
F_H(u,d | X_t)
```

也就是完整聯合機率分佈，不得只保留平均數、中位數、單一分位數或少數幾個分位數。

### 5.3 未來路徑波動

未來路徑波動和終點方向、上下行空間分開定義、訓練及驗證。不得把三類目標混成一個手工加權總分。

## 六、上下行空間的跨商品標準化

令：

```text
R(H,s) = U(H,s) + D(H,s)
```

對每個商品與預測期，使用截至 t 已完成的歷史結果計算 expanding 中位數：

```text
B(H,t) = median({R(H,s) | s + H <= t})
```

模型主要預測：

```text
U_tilde = U / B(H,t)
D_tilde = D / B(H,t)
```

規則：

- `B(H,t)` 只能使用當時已完成標記的歷史結果。
- 1 日與 20 日各自計算。
- 每個商品各自計算。
- 原始 `U`、`D` 仍須保存及顯示。
- 此 expanding 中位數只負責空間目標尺度，不得與同狀態內的突兀程度基準混用。
- 資料不足或分母無效時，標準化結果標記不可用，不偽造為 0。

## 七、正常活動量尺度預測器

系統另建立可解釋且受約束的正常活動量預測器：

```text
S(H,t) = c_H * product(V(j,t) ^ w(H,j))
```

約束：

```text
w(H,j) >= 0
sum(w(H,j)) = 1
```

用途是估計未來正常總活動量：

```text
R(H,t) = U(H,t) + D(H,t)
```

1 日與 20 日分開估計。候選 OHLC 尺度包含：

- Yang-Zhang volatility。
- Parkinson volatility。
- TR 平均數。
- TR 標準差。
- High-Low 波幅平均數。
- High-Low 波幅標準差。

不納入日報酬標準差。

評估誤差：

```text
abs(ln(S(H,t) / R(H,t)))
```

至少輸出：

- 平均絕對 log-ratio 誤差。
- 中位數誤差。
- p90 誤差。
- 各驗證折結果。

若驗證表現實質相同，選擇較少指標、較少自由度的模型。

## 八、同狀態內活動量基準

本次結構狀態開始後，狀態內 OHLC 活動尺度逐步取代狀態開始時的尺度：

```text
S_effective
= S_start ^ (kappa / (kappa + n))
* S_state ^ (n / (kappa + n))
```

其中：

- `S_start` 是狀態開始時可取得的正常活動量尺度。
- `S_state` 是目前這次狀態內已完成資料的活動尺度。
- `n` 是本次狀態內已納入的有效觀測數。
- `kappa` 是由市場預測驗證流程搜尋的正值。

因果順序固定為：

```text
使用截至 t-1 的狀態資料
→ 計算與判定 t
→ 完成後才把 t 加入狀態統計
```

`S_effective` 只用來衡量當日相對本次狀態是否突兀，不得用來定義長期大波動或小波動，否則長期高波動狀態會被自身平均值消除。

## 九、路徑波動特徵

系統要分別保留：

- TR 平均數。
- TR 標準差。
- High-Low 波幅平均數。
- High-Low 波幅標準差。
- Parkinson volatility。
- Yang-Zhang volatility。

每個特徵保存兩種標準化表示：

1. 相對因果 expanding 全歷史中位數的倍數，用於判斷高低波動狀態。
2. 相對本次狀態有效活動尺度的倍數，用於判斷突兀與偏離。

兩種表示不得互換用途。

## 十、路徑波動高低狀態規則

規則文法分三組：

| 群組 | 可選指標 |
|---|---|
| 整體 / 跳空 | Yang-Zhang 或 TR 平均數 |
| 盤中波幅 | Parkinson 或 High-Low 平均數 |
| 不穩定程度 | TR 標準差或 High-Low 標準差 |

限制：

- 每組至多啟用一個指標。
- 至少啟用一組。
- 啟用群組之間以 OR 結合。
- 只能使用「大於門檻」的單調條件。
- 不允許巢狀布林邏輯。
- 不要求連續多日確認。

進入高波動：任一啟用條件超過進入門檻時立即進入。

離開高波動：所有啟用條件都低於各自退出門檻時才離開。

所有群組共用一個遲滯比例：

```text
q_exit(j) = 1 + rho * (q_entry(j) - 1)
```

群組選擇、進入門檻與 `rho` 使用未來實際路徑波動標籤搜尋，不使用策略 P&L。

主要驗證指標為 balanced accuracy。表現相同時依序選擇：

1. 1 至 2 日短暫反轉較少。
2. 離開延遲較短。

診斷至少包含：

- false exit。
- 狀態持續性。
- 切換次數。
- 離開延遲。
- 每次狀態持續長度。

## 十一、終點方向預測狀態

終點方向模型輸出校準後的上漲機率，硬狀態為：

- 上升。
- 不確定。
- 下降。

進入門檻與遲滯比例共同搜尋，不使用策略 P&L。

退出門檻：

```text
p_exit = 0.5 + rho_p * (p_entry - 0.5)
```

主要選擇指標為輸出狀態與實際終點方向之間的樣本外 mutual information，並設最低 support。表現相同時依序選擇：

1. 短暫反轉較少。
2. 進入狀態較保守。

報告至少顯示：

- coverage。
- 各預測狀態的實際上漲率。
- 命中率。
- mutual information。
- 狀態持續時間。
- 機率校準圖與可靠度統計。

## 十二、上下行空間的六區表示

對標準化後的聯合分佈定義：

```text
A(u,d) = (u - d) / (u + d)
M(u,d) = u + d
```

當 `u+d=0` 時不計算 A，交由零值型態處理。

使用方向邊界 `a` 與大小邊界 `m`，從完整聯合分佈積分得到六區機率：

- 上升、小波動。
- 上升、大波動。
- 平衡、小波動。
- 平衡、大波動。
- 下降、小波動。
- 下降、大波動。

完整聯合分佈必須保留。六區向量只是可解釋的衍生表示，不得取代原分佈。

方向參數組分開搜尋：

- `a`。
- 方向信心門檻 `c`。
- 第一名與第二名差距 `g`。
- 方向遲滯 `rho_d`。

大小參數組分開搜尋：

- `m`。
- 大小信心門檻。
- 大小遲滯 `rho_m`。

方向與大小不得混成一個選擇分數；兩組邊界確定後才共同切出六區。

## 十三、空間方向與大小硬狀態

空間方向硬狀態：

- 上升。
- 平衡。
- 下降。
- 不確定。

大小硬狀態：

- 大。
- 小。
- 不確定。

「平衡」代表模型認為上下空間接近；「不確定」代表模型信心不足，兩者不得混用。

方向進入條件必須同時符合：

```text
P_max >= c_entry
P_max - P_second >= g_entry
```

方向退出門檻：

```text
c_exit = 1/3 + rho_d * (c_entry - 1/3)
g_exit = rho_d * g_entry
```

大小為二元機率，退出門檻：

```text
c_mag_exit = 1/2 + rho_m * (c_mag_entry - 1/2)
```

切換規則：

- 目前狀態仍符合退出條件時維持。
- 若目前狀態失效且另一狀態符合進入條件，直接切換。
- 否則輸出不確定。
- 不增加連續多日確認。

方向與大小分別以樣本外 normalized mutual information 搜尋邊界、信心與遲滯，並設最低 support。表現相同時選擇較穩定、較簡單的設定。

舊式：

```text
a_exit = rho * a
```

已被本節的機率遲滯取代，不得實作。

## 十四、1 日與 20 日的階層

20 日負責定義結構市場狀態；1 日負責描述該結構狀態內的短期資訊。

規則：

- 1 日與 20 日輸出各自保存，不平均。
- 衝突組合必須保留，例如「20 日上升、1 日下降」。
- 1 日狀態不得單獨重設本次結構狀態。
- 空間方向、空間大小與六區機率是每日屬性，可控制參數，但不重設結構狀態段。

結構狀態鍵：

```text
StateType = (20 日終點方向, 20 日路徑波動)
```

六種結構狀態：

1. 上升、低波動。
2. 上升、高波動。
3. 下降、低波動。
4. 下降、高波動。
5. 方向不確定、低波動。
6. 方向不確定、高波動。

方向或波動軸經遲滯後改變，即開始新的狀態 occurrence。中途離開後再回到同一 `StateType`，仍是新的 occurrence。

## 十五、同狀態趨勢偏差

在目前結構狀態 occurrence 內，使用截至 t-1 的 log 收盤價與交易日序號做 OLS：

```text
y_hat(x) = alpha + beta * x
```

今日偏差：

```text
Z_trend(t)
= (ln(Close[t]) - y_hat[t])
/ residual_std[t-1]
```

分母是價格相對該趨勢直線的殘差標準差，不是價格標準差或日報酬標準差。

因果順序：

```text
以 t-1 以前資料擬合
→ 評估 t
→ 再把 t 加入 occurrence
```

觀測不足、殘差尺度為 0 或數值無效時，輸出不可用，不偽造為 0。

## 十六、兩條模型路線

建立研究任務時，由使用者選擇一條路線：

1. 可解釋特徵模型。
2. 標準化原始 OHLC 序列模型。

兩條路線：

- 使用相同預測目標與輸出 schema。
- 分開建立任務、訓練、保存與比較。
- 不自動選擇跨路線冠軍。
- 不平均、不 ensemble、不在執行時切換。
- 由使用者在任務完成後自行比較與採用。

### 16.1 可解釋特徵模型

使用稀疏、正則化的廣義加法分佈回歸：

- 單變數平滑效果。
- 至多二階交互作用。
- 不允許三階以上交互作用。
- 只有兩個主效果都存在時，才允許其交互作用。
- 對平滑度與稀疏度施加懲罰。
- 輸出每個主效果曲線與交互作用曲面。

特徵只能使用決策時點已知資料，並遵守多資產研究文件的 FeatureSpec、時間可用性、資料版本與缺值規則。

### 16.2 原始 OHLC 序列模型

每日輸入通道：

```text
ln(Open[t]  / Close[t-1])
ln(High[t]  / Close[t-1])
ln(Low[t]   / Close[t-1])
ln(Close[t] / Close[t-1])
```

模型採小型 causal dilated TCN：

- dilation 依序為 `1, 2, 4, 8, ...`。
- 不使用 attention 或 Transformer。
- 候選回看期為 `5, 10, 20, 40, 60, 120, 250, 500` 個交易日。
- 驗證表現實質相同時選擇較短回看期與較小模型。

## 十七、聯合分佈輸出模型

本章模型中的 `U`、`D` 代表第六章定義的標準化 `U_tilde`、`D_tilde`；原始 log 空間值另行保存，不混入同一模型尺度。因正值尺度除法不改變是否為 0，零值型態定義保持不變。

上下行空間模型先分開處理四種零值型態：

1. `U=0, D=0`。
2. `U>0, D=0`。
3. `U=0, D>0`。
4. `U>0, D>0`。

雙正值部分使用有限二元 lognormal mixture：

```text
(ln U, ln D) | k, X
~ Normal_2(mu_k(X), Sigma_k(X))
```

單邊正值部分使用一元 lognormal mixture。

此結構必須：

- 精確處理零值機率。
- 保留 U 與 D 的相關性。
- 支援偏態與多峰。
- 對正值保有完整 support。
- 直接學習條件密度，不得以歷史案例混合代替。

mixture component 數量 K 由內部驗證選擇；表現實質相同時使用較少 components。

## 十八、訓練與時間驗證

每個預測期、每類目標分開訓練與驗證：

- 終點方向機率。
- 上下行空間聯合分佈。
- 路徑波動輸出。

不得用手工權重把三類 loss 合併成單一選模分數。

### 18.1 Walk-forward

使用者選定的搜尋區間內，使用 purged anchored / expanding walk-forward：

- 日期不得隨機打散。
- 1 日目標 purge 至少 1 個交易日。
- 20 日目標 purge 至少 20 個交易日。
- 正式回測區間保持盲測，不得調整模型、狀態或信心門檻。

### 18.2 聯合分佈 loss

主要 loss：

```text
NLL = -sum(ln p_theta(U_tilde[t], D_tilde[t] | X_<=t))
```

至少與不使用特徵的固定分佈 baseline 比較。

模型通過條件同時包含：

- 聯合 NLL 改善。
- U 邊際誤差檢查。
- D 邊際誤差檢查。
- 四種零值型態 Brier 檢查。
- 六區機率 Brier 檢查。
- 機率校準與 reliability 檢查。

未通過門檻時標記「尚未證明具有預測力」，不得供動態持倉使用。

### 18.3 One-standard-error rule

同一條使用者已選路線內：

```text
mean_NLL(candidate) <= mean_NLL(best) + SE(best)
```

符合者選擇最簡單模型：

- 特徵模型：較少特徵、較少交互作用、較低有效自由度。
- 序列模型：較短回看期、較少參數。
- 聯合分佈：較少 mixture components。

此規則只選擇單一路線內的超參數，不得用來自動比較特徵模型與 TCN。

內部選模完成後，以完整搜尋區間重新擬合並凍結模型。

## 十九、三種動態能力

系統同時提供：

1. 任務層可選的市場訊號標準化。
2. 依預測軟資訊連續調整核心參數。
3. 依六種結構狀態切換核心參數。

市場訊號標準化是任務層設定，可與另外兩種參數模式共存。

每個核心參數獨立選擇一種模式：

- 固定值。
- 單一全域研究值。
- 連續動態。
- 六狀態切換。

同一核心參數不能同時使用連續動態與六狀態切換。不同核心參數可在同一任務中使用不同模式。

## 二十、連續動態公式

每個核心參數 j 沿用既有合法範圍 `[L_j, U_j]`。

```text
q(j,t) = q(j,0)
       + sum(a(j,r) * z(r,t) + b(j,r) * z(r,t)^2)

p(j,t) = L_j + (U_j - L_j) * sigmoid(q(j,t))
```

可用輸入保持分離，包含：

- 1 日終點方向機率。
- 20 日終點方向機率。
- 1 日六區機率。
- 20 日六區機率。
- 路徑波動輸出。
- 同狀態趨勢偏差。
- 其他本文件已確認且可因果取得的標準化預測值。

規則：

- 每個輸入先轉為有界、無量綱值。
- 不建立單一 master score。
- 只允許一次項與二次項。
- 不允許三次以上項。
- 不允許不同輸入彼此相乘。
- 使用者選擇哪些預測量可以影響哪些核心參數。
- 未選取的係數不進入參數空間，不以 0 值假裝存在。

## 二十一、六狀態切換公式

對每個核心參數 j：

```text
q(j,t) = q(j,0)
       + d(j,direction)
       + v(j,volatility)
       + h(j,direction,volatility)
```

其中：

- direction 為上升、下降、方向不確定。
- volatility 為低波動、高波動。
- 方向效果、波動效果與交互作用可分別啟用。
- 使用 sum-to-zero 約束避免不可識別。
- 交互作用允許形成六個不同有效值，但仍可分解來源。
- 狀態切換使用本文件已確認的遲滯，不另外增加連續日確認。

最後仍使用既有 `[L_j,U_j]` 及 sigmoid / clamp 轉成合法參數值。

## 二十二、結構限制與回退

動態有效參數不只要符合單欄上下限，也必須符合跨欄結構限制。

至少包含：

```text
ForceFullThreshold >= ForceEmptyThreshold
```

規則：

- 每日有效參數生成後立即驗證結構限制。
- 無法修復的參數點標記無效，不得送進策略核心。
- `Gamma` 等既有選配基因不得因 K 靜默啟用。
- 固定模式與全域模式必須尊重既有參數包語義。
- 模型、輸入或狀態不可用時，回退至該參數的全域基準值。
- 回退事件必須進入每日診斷，不得靜默發生。

## 二十五、任務生命週期

一次使用 K 的參數研究任務依序為：

1. 使用者選擇模型路線與模型設定。
2. 建立因果訓練資料與目標。
3. 執行 walk-forward 訓練、驗證與校準。
4. 為搜尋區間物化固定的 out-of-fold 每日預測。
5. 凍結模型 artifact、狀態規則與預測 schema。
6. 將 `DynamicParameterSpaceSchema` 交給 M。
7. M 研究動態政策與核心參數，產生穩健候選。
8. 保存模型、動態政策、參數包與標準化回測結果。

限制：

- 模型每個任務 / 設定只訓練一次，不得每個參數評估點重新訓練。
- 搜尋區間必須使用 OOF 預測，不得使用同段資料的 in-sample fitted prediction。
- 正式回測使用搜尋結束時凍結的模型權重、特徵與門檻。
- 已確認的 causal expanding 基準與同狀態統計可隨日更新。
- 投資組合開始前可使用 warmup 歷史初始化模型輸入與狀態，但不得改變帳戶初始現金或持倉。

## 三十、測試要求

### 30.1 因果與資料洩漏

- 每個 t 的特徵只使用截至 t 可取得資料。
- 狀態內統計先算 t，再加入 t。
- `U`、`D` 標籤只出現在訓練目標，不進入同日特徵。
- purge 長度符合預測期。
- 搜尋區間只使用 OOF 預測。
- 正式回測不得回頭調整模型。

### 30.2 數學與狀態

- 驗證 U、D、零值型態與標準化公式。
- 驗證六區機率和為 1。
- 驗證方向、大小與路徑波動遲滯。
- 驗證平衡與不確定不混用。
- 驗證 occurrence 重設規則。
- 驗證趨勢偏差使用 t-1 擬合。
- 驗證連續模式永遠落在合法範圍。
- 驗證六狀態 sum-to-zero 約束。
- 驗證所有跨參數結構限制。

### 30.3 一致性

- 同一模型與資料重跑得到相同預測。
- 參數研究與回測頁使用同一有效參數提供器。
- 相同 execution mode 產生相同交易語義。
- K 未啟用時，結果與既有固定參數回測一致。
- 模型不可用時，回退值與事件紀錄一致。

### 30.4 保存與快取

- artifact hash 變更會使不相容快取失效。
- 相同研究點可重用同一標準化回測結果。
- 取消與恢復不會產生重複或假完成結果。
- 採用、回測與市場狀態頁能追溯同一完整模型包。
- N 唯讀介面固定到同一 artifact/report snapshot 與內容 hash，且讀取不會觸發訓練、預測、狀態物化或回測。
