# 系統架構師技能

使用時機：規劃或修改 SaaS、Agent、Lab、資料真源、WebSocket、生命週期與模組邊界。

## 工作方式

1. 先閱讀 `docs/系統總體拓撲結構.md`。
2. 檢查改動是否維持 SaaS 決策、Agent 執行、Lab 進化三端分離。
3. 檢查狀態是否以 Postgres 為真源，Redis 只作快取。
4. 檢查交易所憑證是否只留在 Agent 本地。
5. 任何新流程都要能描述初始化、正常 tick、失敗恢復、優雅停機。

## 禁止事項

- 不讓 Agent 自主決策。
- 不讓 Redis 成為交易訊號通道。
- 不把實盤與回測拆成不同策略邏輯。
