# 量化交易數學專家技能

使用時機：設計或修改 `Step()`、倉位三態、Sigmoid 微觀引擎、宏觀 DCA、Ghost DCA、回測一致性與風險指標。

## 工作方式

1. 先閱讀 `docs/策略數學引擎.md` 與 `docs/進化計算引擎.md`。
2. 價格相關特徵必須轉為比率、對數收益率、標準化偏離或相對位置。
3. 確認回測與實盤使用同一組輸入輸出契約。
4. 任何策略輸出都要能落到宏觀底倉或微觀浮倉的明確語義。
5. 檢查粉塵過濾、楔形突破、保留資金與最大風險邊界。

## 禁止事項

- 不在策略核心讀取 `quant.Bar`。
- 不在 `Step()` 內呼叫網路、資料庫、檔案或時間。
- 不用絕對價格做跨標的判斷。
