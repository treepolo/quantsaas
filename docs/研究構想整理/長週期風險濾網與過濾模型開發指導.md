# 長週期風險濾網與過濾模型開發指導

> 狀態：P07 已完成；K / M 的不可變設定契約已預留，待各自階段接入
>
> 對應大點：D. 不進場 / 趨勢濾網機制
>
> 用途：定義以 N 月線下彎作為長週期風險濾網時，回測、參數搜尋與圖表應如何運作。此文件不是三份真源文件，不取代既有穩定系統規格。

## 一、系統定位

長週期風險濾網用來處理長週期熊市或長期風險環境惡化。

它不是核心策略訊號，也不是每日漲跌預測器。

它是一個上層過濾模型：

```text
實務模型照常運行
過濾模型依濾網狀態決定是否持倉
回測績效以過濾模型 NAV / 權重為準
```

## 二、依賴關係

本功能依賴：

```text
docs/研究構想整理/回測核心模組開發指導.md
docs/研究構想整理/標準化回測結果保存機制開發指導.md
docs/研究構想整理/報酬分析共用模組開發指導.md
docs/研究構想整理/計算任務與快取掃描工具開發指導.md
```

原因：

- 濾網必須套在一致的回測核心之上。
- 濾網開關、N 月線設定、交易規則與過濾模型路徑必須保存，否則結果不可重現。
- 濾網結果需要被報酬分析讀取。
- 搜尋與回測中的批次計算必須支援總計算量、進度、取消與快取。

本功能會作為 M 不可變研究設定的一部分，也可套用於 K 動態參數回測：

```text
docs/研究構想整理/動態適應參數機制開發指導.md
docs/研究構想整理/參數績效地形研究與穩健候選產生系統開發指導.md
```

開發順序上，本功能應晚於回測核心模組與標準化回測結果保存機制。

## 三、設定項目

長週期風險濾網設定包含：

- 是否啟用濾網。
- N 月線長度。
- 交易規則 / execution mode。
- 濾網版本。

預設狀態：

```text
濾網預設為啟用。
預設 N 月線長度可由前端設定初始值，但不得寫死成不可改。
```

使用者必須可以在下列位置設定：

- 既有參數搜尋或 M 研究任務建立時。
- 回測頁臨時回測時。
- 既有參數事後調整濾網設定時。

## 四、N 月線資料來源

本功能不需要獨立月線資料。

月收盤序列由日 K 組成：

```text
每個月最後一個交易日的收盤價 = 該月月收盤價
```

月 K 尚未完成前不得判定當月濾網狀態。

每個月最後一個交易日收盤後，才產生該月的濾網判定。

## 五、濾網觸發條件

使用最近 N 個已完成月份的月收盤價計算 N 月均線。

若：

```text
本月 N 月均線 < 上月 N 月均線
```

則從下一個可執行交易時點開始進入濾網狀態。

若原本已在濾網狀態，且：

```text
本月 N 月均線 > 上月 N 月均線
```

則從下一個可執行交易時點開始解除濾網狀態。

若兩者相等，濾網狀態維持不變。

## 六、實務模型與過濾模型

本功能必須分離兩條模型路徑：

### 6.1 實務模型

實務模型照常運行。

即使濾網觸發，實務模型仍然每日依原策略、原參數、原交易規則與原回測假設推進。

實務模型輸出仍包含：

- 原始策略 NAV。
- 實務模型目標權重。
- 實務模型實際權重。
- 原本會發生的交易。

實務模型不得因濾網狀態而停止、平倉或改寫內部狀態。

### 6.2 過濾模型

過濾模型是回測績效使用的模型。

濾網未啟用或濾網未觸發時：

```text
過濾模型跟隨實務模型持倉與交易結果。
```

濾網觸發時：

```text
過濾模型依該參數選定的交易規則平倉。
過濾模型進入全現金狀態。
過濾模型在濾網狀態中完全禁止買入。
```

濾網解除時：

```text
過濾模型依該參數選定的交易規則，重新依照實務模型當下目標 / 實際狀態建倉。
```

回測頁、參數搜尋頁與報酬分析若選用濾網版本，績效以過濾模型 NAV、權重與交易為準。

## 七、交易規則

濾網平倉與重新建倉必須使用該參數或該回測設定選定的交易規則。

若 execution mode 為收盤成交：

```text
月末收盤後產生濾網判定。
同一根月末日 K 的收盤價可作為濾網交易成交價。
```

若 execution mode 為隔日開盤成交：

```text
月末收盤後產生濾網判定。
下一個交易日開盤價作為濾網交易成交價。
```

所有成交仍需套用同一組手續費、滑價與成本設定。

## 八、保存與 metadata

下列資訊必須與參數搜尋結果、回測結果或標準化回測結果一起保存：

- 是否啟用濾網。
- N 月線長度。
- 濾網版本。
- 交易規則 / execution mode。
- 濾網狀態序列。
- 過濾模型 NAV 序列。
- 過濾模型權重序列。
- 濾網觸發 / 解除事件。

若參數搜尋時啟用濾網，產出的參數必須帶有該濾網設定。

若 M 研究設定啟用濾網，每個評估點、穩健區域與候選都必須引用同一份濾網設定。修改是否啟用、N 月線長度、版本或 execution mode 時，必須建立新的研究設定，不得把不同濾網條件的評估點混成同一張績效地形。

若搭配 K，執行順序固定為：

```text
K 計算每日有效核心參數
→ 實務模型照常呼叫既有 Step()
→ D 過濾模型依月線狀態決定實際持倉
```

過濾狀態不得停止 K 預測、狀態更新或實務模型推進，否則解除濾網時無法依當時實務模型狀態正確重建倉位。

若回測頁臨時套用濾網，該濾網設定屬於回測設定，不得靜默寫回原參數。

N 通用研究比較不把 D 設定建立成獨立研究結果。濾網開關、N 月線長度、交易規則、過濾模型版本及觸發區間，必須由 BacktestResult 或 M 研究結果的背景區塊提供給 N；不同設定會影響逐區塊相容判定，不得被靜默忽略。完整 N 規格見：

```text
docs/研究構想整理/通用研究結果與參數比較工具開發指導.md
```

## 九、圖表顯示

圖表必須能顯示：

- 實務模型 NAV。
- 過濾模型 NAV。
- Ghost DCA NAV。
- 濾網生效區間。
- 濾網觸發點。
- 濾網解除點。

濾網生效區間需以背景色或區段標記顯示，方便觀察長週期避險效果。

Tooltip 至少顯示：

- 日期。
- 濾網是否啟用。
- 濾網是否處於觸發狀態。
- N 月線值。
- 上月 N 月線值。
- 實務模型權重。
- 過濾模型權重。

## 十、計算任務要求

本功能若在既有參數搜尋、M 參數研究、批次回測或大量比較中觸發批次計算，必須遵守：

- 顯示總計算量。
- 顯示進度。
- 支援取消。
- 已完成結果可快取。
- 取消後不得留下被標示為完成的半成品。

完整共通規則見：

```text
docs/研究構想整理/計算任務與快取掃描工具開發指導.md
```

## 十一、完成判準

此功能完成後，至少必須滿足：

- 可設定是否啟用長週期風險濾網。
- 可設定 N 月線長度。
- 可由日 K 月末收盤價計算月收盤序列。
- 月 K 未完成前不判定當月濾網。
- 可分離實務模型與過濾模型。
- 濾網觸發時，過濾模型依交易規則平倉，實務模型繼續運行。
- 濾網解除時，過濾模型依交易規則重新依照實務模型建倉。
- 回測績效可選用過濾模型結果。
- 濾網設定與過濾模型路徑可保存並重現。
- 圖表可標示濾網生效區間。
- M 不會把不同濾網設定的評估點混入同一績效地形。
- K 搭配濾網時，實務模型與 K 狀態在過濾期間仍持續推進。
