# 備援機制完整使用教學

這份文件是「遇到狀況時要去哪裡、按什麼、看什麼」的總整理。細節文件仍保留在：

- `docs/緊急試算工具使用說明.md`
- `docs/SOXL21離線試算頁使用說明.md`
- `docs/GitHub Actions SOXL自動試算設定.md`
- `docs/雲端備份與還原使用說明.md`

## 一、你會用到哪些服務

目前備援會用到三個地方：

| 位置 | 用途 |
|---|---|
| GitHub | 保存程式碼、加密 SOXL #21 備援資料包、每日自動試算結果 |
| Google Drive | 保存完整系統加密備份 |
| 本機 Windows | 平常跑完整軟體、產生備份、手動緊急試算 |

Google Drive 備份資料夾：

```text
QuantSaaSBackups
```

## 二、每天要看 SOXL #21 權重

最方便的方式是看 GitHub：

```text
secure-backups/emergency/soxl-21-latest.md
```

或到：

```text
GitHub -> Actions -> SOXL 緊急每日試算
```

GitHub Actions 會自動跑：

```text
台灣時間 週二到週六 07:30 左右
```

它會在美股收盤後：

1. 解密 SOXL #21 備援資料包。
2. 從 Yahoo 抓 SOXL 最新日 K。
3. 計算最新基準模型目標權重。
4. 更新 `secure-backups/emergency/soxl-21-latest.md`。

如果美股休市或週末，最新日期維持上一個交易日是正常現象。

## 三、如果 GitHub Actions 沒有成功

若 GitHub Actions 失敗、Yahoo 暫時抓不到資料，或你已經知道 SOXL 收盤價但自動資料還沒更新，可以用本機手動輸入：

```text
SOXL21手動輸入收盤價試算.bat
```

它會要求你輸入：

1. 日期
2. SOXL 收盤價

然後輸出最新基準模型目標權重。

注意：這個 BAT 需要本機有資料包，至少要有其中一個：

```text
D:\量化交易\emergency\soxl-21.bundle.json
```

或：

```text
D:\量化交易\secure-backups\emergency\soxl-21.bundle.json.enc
```

如果明文資料包不存在，它會嘗試用加密備份解開；這時需要輸入 `EMERGENCY_BUNDLE_PASSWORD` 那組密碼。

如果只是要用目前資料看最新結果，雙擊：

```text
SOXL21查看最新試算.bat
```

## 四、如果換新電腦但只想先算 SOXL 權重

新電腦最低限度流程：

1. 登入 GitHub。
2. 下載或 clone 專案。
3. 確認專案裡有：

```text
secure-backups/emergency/soxl-21.bundle.json.enc
```

4. 雙擊：

```text
SOXL21手動輸入收盤價試算.bat
```

5. 輸入 `EMERGENCY_BUNDLE_PASSWORD` 解密。
6. 輸入最新 SOXL 收盤價。
7. 取得最新基準模型目標權重。

這條路線不需要先還原完整資料庫。

## 五、如果只剩瀏覽器或手機

可以用離線網頁：

```text
SOXL21離線試算.html
```

用途是：沒有 Docker、沒有完整系統、只有手機或臨時電腦時，仍能做最低限度試算。

大致流程：

1. 從 GitHub 下載 `SOXL21離線試算.html`。
2. 匯入 SOXL #21 加密資料包。
3. 輸入備援密碼解密。
4. 手動輸入 SOXL 收盤價。
5. 看最新基準模型目標權重。

這是最後防線；Go CLI 仍是計算真源，離線網頁是方便備援。

## 六、如果 #21 參數更新了

如果你之後改採用新的 SOXL 參數，或 #21 的正式資料包需要更新，主系統正常時雙擊：

```text
匯出SOXL21加密備份到GitHub.bat
```

它會：

1. 從資料庫匯出 SOXL #21 備援資料包。
2. 加密成：

```text
secure-backups/emergency/soxl-21.bundle.json.enc
```

3. 推送到 GitHub。

如果只是重新上傳現有加密資料包，也可以用：

```text
上傳SOXL21加密資料包到GitHub.bat
```

## 七、完整系統備份

完整備份用來防止電腦故障、D 槽故障、資料庫毀損。

本機備份位置：

```text
D:\量化交易\backups
```

Google Drive 備份位置：

```text
Google Drive / QuantSaaSBackups
```

你可以手動跑：

```text
建立每日增量備份.bat
建立每週全量備份.bat
建立手動全量備份.bat
```

備份會先壓縮再加密，上傳到 Google Drive 的也是加密檔。

## 八、自動備份排程

若要建立自動排程，雙擊：

```text
設定自動備份排程.bat
```

它會建立：

```text
每日 08:10：每日增量備份
每週日 09:10：每週全量備份
```

自動排程需要兩個 Windows 使用者環境變數：

```text
QUANTSAAS_BACKUP_PASSWORD
QUANTSAAS_BACKUP_REMOTE
```

目前 Google Drive 目的地應為：

```text
QUANTSAAS_BACKUP_REMOTE = gdrive:QuantSaaSBackups
```

如果要重新設定 Google Drive，雙擊：

```text
設定GoogleDrive備份目的地.bat
```

## 九、如果整台電腦壞了，要還原完整系統

新電腦完整還原流程：

1. 安裝 Git。
2. 安裝 Docker Desktop。
3. 從 GitHub clone 專案。
4. 從 Google Drive `QuantSaaSBackups` 下載最近一次全量備份。
5. 雙擊：

```text
還原全量備份.bat
```

6. 貼上該全量備份 `.zip.enc` 路徑。
7. 如果全量備份後還有每日增量備份，依日期順序逐一雙擊：

```text
套用增量備份.bat
```

8. 啟動 Docker compose。
9. 登入系統檢查：

- 行情資料
- 商品清單與排序
- 參數庫
- 採用參數狀態
- 回測與研究資料

注意：`還原全量備份.bat` 會清空目前 PostgreSQL 的 `public` schema，再匯入備份。只在新環境、空資料庫，或你確定要覆蓋目前資料時使用。

## 十、平常最重要的幾個入口

| 情境 | 入口 |
|---|---|
| 每天看 SOXL #21 權重 | GitHub `secure-backups/emergency/soxl-21-latest.md` |
| GitHub 自動試算狀態 | GitHub `Actions -> SOXL 緊急每日試算` |
| 手動輸入 SOXL 收盤價 | `SOXL21手動輸入收盤價試算.bat` |
| 看本機最新試算 | `SOXL21查看最新試算.bat` |
| 手動做完整保險備份 | `建立手動全量備份.bat` |
| 建立自動備份排程 | `設定自動備份排程.bat` |
| Google Drive 備份資料夾 | `QuantSaaSBackups` |
| 新電腦完整還原 | `還原全量備份.bat` + `套用增量備份.bat` |

## 十一、這套備援覆蓋哪些風險

| 風險 | 對應機制 |
|---|---|
| 主電腦沒開 | GitHub Actions 每日試算 |
| Yahoo 自動資料失敗 | 手動輸入 SOXL 收盤價 |
| Docker 或資料庫暫時壞掉 | SOXL 緊急試算工具 |
| 只有手機或臨時電腦 | `SOXL21離線試算.html` |
| 本機資料庫毀損 | 全量備份 + 增量備份 |
| 整台電腦壞掉 | GitHub 專案 + Google Drive 加密備份 |

## 十二、重要密碼提醒

會用到兩種密碼或秘密：

| 名稱 | 用途 |
|---|---|
| `EMERGENCY_BUNDLE_PASSWORD` | SOXL #21 緊急資料包解密，GitHub Actions 也會用 |
| `QUANTSAAS_BACKUP_PASSWORD` | 完整系統備份 `.zip.enc` 解密 |

請不要把密碼放進：

- GitHub 程式碼
- 文件
- 截圖
- 聊天訊息

如果忘記密碼，加密備份就無法解開。
