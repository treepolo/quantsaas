> 狀態：C-01 至 C-08 全部規格已由使用者確認；P12 已完成開發與驗收
>
> 對應大點：C. 參數可獲利 K 線樣貌反推
>
> 文件定位：本文件是新研究功能的完整開發指導，不是三份既有穩定系統真源文件，也不批准任何縮水版、骨架或暫時替代公式。
>
> 開發型態：預設一次到位，不採 MVP。若日後確實需要拆階段，必須先依 `docs/重大更新開發守則.md` 重新列出每階段完整範圍、排除項、測試與最終補齊計畫。

## 一、研究目的

本功能固定一組由使用者選定的既有參數，反向搜尋能讓該參數獲利或跑贏 DCA 的合成 K 線，回答：

```text
哪些完整 K 線路徑能讓這組參數表現良好？
這些可獲利路徑是否具有充分多樣性？
還是只有少數非常特殊、相近的路徑能讓它獲利？
```

參數在 C 中只是固定的回測輸入。C 不搜尋、不修改、不封裝、不評分參數，也不建立另一套參數管理系統。

本功能研究的是一組固定參數對不同完整行情路徑的反應，不是從一條歷史行情切出既有獲利片段。

## 二、明確不屬於本功能的內容

C 不得被實作成：

- 從歷史回測蒐集獲利區間。
- 尋找與歷史某段 K 線最相似的情境。
- 依 K 線型態直接下單。
- 預測真實市場下一段行情。
- 把搜尋樣本比例解讀為真實市場機率。
- 修改、培養、演化或自動採用參數。
- E 的 K 線片段裁切、重排與複製。
- L 的既有行情微幅擾動。
- J 或 M 的參數績效地形。
- 隨機遊走產生器或無限自由度的任意圖形塗鴉。

C 可以由參數庫、M 候選或已保存回測結果預填一組參數，但這些來源都只提供固定回測輸入，不改變上述邊界。

## 三、方法定位

### 3.1 數值反推

C 採數值反推，不嘗試把回測核心化簡成封閉形式並做符號反解。

令：

```text
theta = 固定參數
x     = 一條完整生成行情
R(theta, x) = 共用回測核心對該參數與行情產生的結果
```

C 搜尋的是符合目標條件的行情集合：

```text
X_A = {x | q_rel(x) > 0}
X_B = {x | q_rel(x) > 0 且 q_abs(x) > 0}
```

每一條行情都必須實際經過共用回測核心，不使用近似損益模型替代正式回測。

### 3.2 品質多樣性搜尋

本功能採 Quality-Diversity 的方向，不只尋找單一最高報酬路徑。主要搜尋方法固定為 Multi-Objective MAP-Elites，並以 CVT 劃分高維行為空間。

採用這個方法的原因是：

- 研究目標是取得許多不同 K 線樣貌，而不是單一最佳樣本。
- 每個行為區域內同時保留 `q_rel` 與 `q_abs` 的 Pareto 表現。
- 高維行為特徵不適合建立二十維笛卡兒格點。
- 搜尋結果可以同時回答覆蓋範圍、可獲利區域與局部失敗邊界。

研究背景：

- MAP-Elites：[Illuminating Search Spaces by Mapping Elites](https://arxiv.org/abs/1504.04909)
- Quality-Diversity 綜述：[Quality Diversity: A New Frontier for Evolutionary Computation](https://www.frontiersin.org/journals/robotics-and-ai/articles/10.3389/frobt.2016.00040/full)
- Multi-Objective MAP-Elites：[Multi-Objective Quality Diversity Optimization](https://arxiv.org/abs/2202.03057)
- CVT-MAP-Elites：[Using Centroidal Voronoi Tessellations to Scale Up the Multi-dimensional Archive of Phenotypic Elites Algorithm](https://arxiv.org/abs/1610.05729)
- Directional variation：[Discovering the Elite Hypervolume by Leveraging Interspecies Correlation](https://arxiv.org/abs/1804.03906)

這些方法只提供搜尋架構，不代表搜尋樣本的頻率是真實市場發生機率。

## 八、W 與 H

### 8.1 定義

每條生成行情由兩段組成：

```text
W = 暖身／歷史上下文段
H = 正式評估段
```

W 與 H 都由搜尋器生成，也都必須保存及顯示。不能用固定歷史行情替代 W。

### 8.2 W 長度

W 自動等於所選參數在既有執行邏輯下所需的最大暖身長度，不寫死為 112 或其他常數。

所需長度必須由既有執行邏輯的 metadata 回報，C 不得解析程式碼猜測。若無法取得有限且明確的暖身長度，研究不得開始。

W 必須涵蓋月末判定等實際會使用的歷史需求，而不只計算日線指標的數量。

### 8.3 H 長度

H 由使用者設定，例如 20、60、120、250 個交易日，但不限制只能使用這些預設值。

不同 H、不同 H 起始日期或不同交易日曆屬於不同研究。

### 8.4 暖身與績效時間

W 的用途只有：

- 提供價格與日期歷史。
- 初始化既有價格衍生狀態。
- 讓 H 第一日能使用完整歷史上下文。

W 期間：

- 不交易。
- 不計算成交成本。
- 不建立 NAV。
- 不投入或提取現金。
- 不納入 `q_rel`、`q_abs` 或任何 H 績效。

H 開始時，參數與 DCA 使用相同固定起始本金。參數從 W 已建立的狀態開始執行；DCA 依既有基準語義在 H 期初一次投入並持有。

### 8.5 日期

日期來自所選商品／週期可用的既有交易日曆：

- 使用者選擇 H 起始日期。
- H 使用起始日起的有效交易日。
- W 使用 H 起始日前的有效交易日。
- 生成行情保留這些日期，使月末及跨月規則可重現。

## 九、現金流與 DCA

C 中固定：

```text
參數每月投入 = 0
DCA 每月投入 = 0
其他外部現金流 = 0
```

DCA 是 H 期初一次投入並持有相同生成行情的基準。C 不從來源回測複製每月投入設定。

前端必須明確顯示「本研究固定月投入為 0」，但不得要求使用者再設定一次。

## 十、K 線四座標表示

對每根 K 線定義：

```text
g_t = ln(Open_t / Close_(t-1))
b_t = ln(Close_t / Open_t)
u_t = ln(High_t / max(Open_t, Close_t))        >= 0
d_t = ln(min(Open_t, Close_t) / Low_t)         >= 0
```

其中：

- `g` 表示相對前收的隔夜跳空。
- `b` 表示開盤至收盤的實體方向與幅度。
- `u` 表示上影線相對實體上緣的對數距離。
- `d` 表示下影線相對實體下緣的對數距離。

重建公式：

```text
Open_t  = Close_(t-1) * exp(g_t)
Close_t = Open_t * exp(b_t)
High_t  = max(Open_t, Close_t) * exp(u_t)
Low_t   = min(Open_t, Close_t) / exp(d_t)
```

此表示自然保證：

- 價格為正。
- `High >= max(Open, Close)`。
- `Low <= min(Open, Close)`。
- 路徑不依賴絕對價格尺度。
- 跳空、實體與上下影線可以分開搜尋。

第一根 W K 線以前一個 canonical 起始收盤價重建。該起始價只是數值與顯示基準，不是搜尋維度，不進入特徵、距離或研究結論。圖表可以把整條路徑重新基準化顯示。

Volume 不在 C 的生成範圍內。不得虛構成交量；若既有執行邏輯必須依賴 Volume，該參數不能在缺乏已確認 Volume 生成規格時啟動 C。

## 十一、校準資料與搜尋邊界

### 11.1 校準來源

使用者選擇一個或多個合法行情資料及各自日期區間。所有來源必須：

- 與 C 研究使用相同 K 線週期。
- 具有合法 OHLC。
- 具有不可變版本或內容 hash。
- 顯示實際納入的 K 線數與可用 `g、b、u、d` 樣本數。

多個來源只用來確立可搜尋的合法幅度範圍，不建立歷史情境相似度、機率或抽樣權重。

### 11.2 自動邊界

初始邊界使用所選資料範圍內完整觀測極值：

```text
g_min = min(g)
g_max = max(g)
b_min = min(b)
b_max = max(b)
u_min = 0
u_max = max(u)
d_min = 0
d_max = max(d)
```

不得默默裁掉離群值、Winsorize、使用百分位截尾或縮窄尾端。

選取區間第一根 K 線若沒有可用前收，只不計算該根的 `g`；`b、u、d` 仍可使用。系統必須顯示各座標實際樣本數。

### 11.3 人工調整

使用者可以在正式建立研究前修改自動邊界。最終邊界必須：

- 通過合法性檢查。
- 顯示與觀測極值的差異。
- 與校準來源、區間、版本及內容 hash 一起凍結。

研究開始後不得修改邊界。不同邊界的結果不得合併成同一 CVT、覆蓋率或通過比例。

### 11.4 禁止的搜尋限制

C 不設定：

- 全路徑最終報酬上限或下限。
- 整條路徑趨勢限制。
- 必須類似任一歷史區間的限制。
- 依歷史出現頻率加權。
- 只允許歷史曾出現的座標組合。

唯一硬邊界是每根 K 線的 `g、b、u、d` 合法範圍及 OHLC 合法性。

## 十二、直接完整路徑基因

搜尋個體就是 W＋H 的完整四座標序列：

```text
x = [(g_1,b_1,u_1,d_1), ..., (g_(W+H),b_(W+H),u_(W+H),d_(W+H))]
```

不得先壓縮成少量形狀參數、預先定義的牛熊模板或學習式生成器。這是為了避免生成器本身限制可發現的 K 線多樣性。

搜尋內部先依最終邊界把四個通道各自正規化到 `[0,1]`。變異完成後再轉回原始對數座標並重建 OHLC。

若變異越過 `[0,1]`，使用反射邊界：

```text
小於 0 時向內反射
大於 1 時向內反射
若一次越過多個區間，持續反射直到回到 [0,1]
```

不得直接截斷到 0 或 1，避免大量樣本堆積在邊界。

## 十三、績效目標

對每條合法生成行情只執行一次參數回測及一次相同行情的 DCA 基準計算。

定義：

```text
q_rel = ln(參數期末 NAV / DCA 期末 NAV)
q_abs = 參數期末 NAV / 參數期初 NAV - 1
```

兩個正式研究目標：

```text
目標 A：q_rel > 0
目標 B：q_rel > 0 且 q_abs > 0
```

意義：

- A：參數跑贏 DCA，即使參數本身仍虧損也保留研究意義。
- B：參數跑贏 DCA，而且參數本身有正報酬。
- B 必然是 A 的子集合。

四種結果狀態必須保留：

| 狀態 | `q_rel` | `q_abs` | 意義 |
|---|---:|---:|---|
| A＋B | `> 0` | `> 0` | 跑贏 DCA 且正報酬 |
| 只有 A | `> 0` | `<= 0` | 跑贏 DCA但仍虧損 |
| 正報酬但輸 DCA | `<= 0` | `> 0` | 本身賺錢但基準更好 |
| 兩者皆否 | `<= 0` | `<= 0` | 未跑贏且未獲利 |

不得把 `q_rel` 與 `q_abs` 加權成單一分數。MOME 在每個 cell 中以兩者作為共同最大化的 Pareto 目標。

若共用回測核心已有資產耗盡或其他極端結果語義，C 必須原樣沿用。C 不建立另一套損益或破產定義。

## 十四、MOME 搜尋

### 14.1 單次評估

每條路徑的評估順序固定：

1. 取得 canonical 四座標。
2. 重建 W＋H OHLC。
3. 驗證日期、邊界與 OHLC。
4. 計算 W/H 二十項行為特徵。
5. 指派 CVT cell。
6. 呼叫共用回測核心計算 H。
7. 計算 `q_rel`、`q_abs` 及四種狀態。
8. 更新工作 archive、A/B map、統計與永久保存集合。

同一路徑不得為 A 與 B 重跑兩次回測。

### 14.2 每個 cell 的活躍父代

每個 CVT cell 最多保留 P 個活躍父代。Pareto dominance 定義：

```text
a 不劣於 b：q_rel_a >= q_rel_b 且 q_abs_a >= q_abs_b
a 支配 b：a 不劣於 b，且至少一項嚴格較大
```

先移除被支配點；若非支配點仍超過 P：

- 保留 `q_rel` 極端與 `q_abs` 極端。
- 其餘名額使用完整路徑 `D_total` 的多樣性擁擠選擇。
- 所有同分 tie 使用固定 hash 排序，確保可重現。

P 只限制活躍父代，不得刪除永久研究結果。

工作 archive 可以保留未符合 A/B 的有效點作為搜尋踏腳石。A 與 B 顯示地圖則分別只呈現符合各自目標的結果。

### 14.3 CVT cell 共用

A 與 B 必須使用同一組凍結 CVT 中心，才能比較覆蓋範圍。不得為了讓 B 看起來較完整而另建一套 cell。

## 十五、變異與產生操作

搜尋操作固定包含：

1. 全域隨機移民。
2. 單點／局部變異。
3. 多尺度連續區塊變異。
4. 區塊交叉。
5. Directional variation。

### 15.1 全域隨機移民

在正規化 `[0,1]` 空間獨立產生完整路徑，用來探索尚未觸及的區域。

這不是依歷史機率抽樣；每個座標只受最終搜尋邊界限制。

### 15.2 單點／局部變異

選取一根或少數相鄰 K 線，修改其中一個或多個 `g、b、u、d` 通道，其餘路徑保持不變。

### 15.3 多尺度區塊變異

連續區塊長度使用：

```text
1, 2, 4, 8, ...，直到涵蓋 W+H 的最大有效尺度
```

最後必須包含完整 `W+H` 尺度，即使長度不是 2 的冪次。

此操作讓搜尋能同時改變單日細節、中期段落與整體路徑。

### 15.4 區塊交叉

從兩個父代選取相同時間位置的連續區塊交換或組合。不得改變 W/H 長度與日期。

### 15.5 Directional variation

利用兩個既有父代在正規化路徑空間中的方向差異提出新路徑，再經反射邊界修正。

### 15.6 操作配額與版本

五種操作都必須取得固定、非零的預算配額，不能因短期績效自動把某種操作權重降為零。第一個正式版本採近似均分配額，餘數依固定操作順序分配。

需要父代的操作在父代數不足時，該位置暫以全域隨機移民補足，並保存原排定操作與實際 fallback。所有操作、尺度、幅度、父代、seed 位置及版本都必須保存。

## 十六、工作集合與永久研究結果

搜尋工作集合和永久研究結果必須分開。

### 16.1 永久保存規則

以下路徑永久保存：

- 所有符合 A 或 B 的路徑，稱為可獲利 anchor。
- 由可獲利 anchor 直接經單點、區塊、交叉或 directional variation 產生的所有子路徑，不論結果好壞。
- 後來導向新可獲利 anchor 所必需的中間祖先鏈。

區塊交叉或 directional variation 只要至少一個直接父代是可獲利 anchor，子路徑就適用第二條。

### 16.2 不永久保存的內容

純全域隨機移民若不符合 A/B：

- 不保存完整路徑為永久研究結果。
- 仍保留 cell 聚合計數、四種狀態計數與工作 checkpoint 所需資訊。

失敗的直接子路徑雖然永久保存，但不會因此讓其所有後代自動永久保存。若其後代後來成為可獲利 anchor，才把連接該 anchor 所需的祖先鏈補升級為永久結果。

### 16.3 去重與血緣

- 完全相同路徑只保存一份 immutable payload。
- 路徑 hash 相同時重用同一 payload 與相同回測結果。
- 每一條不同的產生關係都必須保存成獨立 lineage edge。
- 一條路徑可以有多個父代、出現在不同 batch，或被不同 anchor 重新產生。
- 去重不得抹除任何血緣。

## 十七、二十項可解釋行為特徵

W 與 H 分開計算相同十項特徵，共二十維。

對每根 K 線：

```text
r_t = ln(Close_t / Close_(t-1)) = g_t + b_t

TR_t = max(
  ln(High_t / Low_t),
  abs(ln(High_t / Close_(t-1))),
  abs(ln(Low_t / Close_(t-1)))
)
```

每段的十項特徵：

### 17.1 平均報酬

```text
mean(r)
```

保留整段方向與平均速度。

### 17.2 趨勢效率

```text
abs(sum(r)) / sum(abs(r))
```

表示總位移相對總移動量。分母為零時定義為 0。

### 17.3 最大回撤形狀

```text
log 最大回撤幅度 / sum(abs(r))
```

其中 log 最大回撤幅度是累積 log 價格從既有高點到後續低點的最大下降距離。分母為零時定義為 0。

### 17.4 最大上行幅度形狀

```text
log 最大 run-up 幅度 / sum(abs(r))
```

其中 run-up 是既有低點到後續高點的最大上升距離。分母為零時定義為 0。

### 17.5 方向反轉率

移除 `r = 0` 的日子後，計算相鄰非零報酬符號改變的比例。少於兩個非零報酬時定義為 0。

### 17.6 平均 TR

```text
mean(TR)
```

### 17.7 活動集中度

```text
w_t = TR_t / sum(TR)
concentration = (n * sum(w_t^2) - 1) / (n - 1)
```

`n` 是該段 K 線數。`sum(TR)=0` 或 `n<=1` 時定義為 0。

### 17.8 跳空占比

```text
sum(abs(g)) / sum(abs(g) + abs(b))
```

分母為零時定義為 0。

### 17.9 影線占比

```text
sum(u + d) / sum(abs(b) + u + d)
```

分母為零時定義為 0。

### 17.10 影線不對稱

```text
sum(u - d) / sum(u + d)
```

分母為零時定義為 0。

### 17.11 禁止混入績效

這二十項只能描述生成行情本身。不得加入：

- 參數報酬。
- DCA 報酬。
- 實際持倉。
- A/B 狀態。
- 任何參數內部訊號。

否則行為空間會把「行情長什麼樣」與「參數賺多少」混成同一件事。

## 十八、完整路徑距離

行為特徵用來分區；完整路徑距離用來區分同一或相近分區中的實際 K 線差異。

### 18.1 通道正規化

依研究凍結邊界，分別把 `g、b、u、d` 映射到 `[0,1]`。某通道上下界完全相同時，該通道正規化值定義為 0。

### 18.2 多解析度時間對齊

W 與 H 分開處理。每段使用：

```text
1, 2, 4, 8, ...，以及完整 bar 數
```

這裡的數字是時間分區數。每個尺度把整段依時間順序切成盡可能等長的連續區塊，再計算每個區塊四個通道的平均值。

同一尺度、同一區塊及同一通道逐一比較兩條路徑，最後計算 RMS。

### 18.3 距離

```text
D_W = RMS(W 所有尺度、區塊與通道差異)
D_H = RMS(H 所有尺度、區塊與通道差異)

D_total = sqrt((D_W^2 + D_H^2) / 2)
```

必須保存並顯示 `D_W`、`D_H`、`D_total`。

距離具有：

- 同一路徑距離為 0。
- 對稱性。
- W/H 等權。
- 時間位置敏感性。

不得使用 DTW 對齊，因為「何時發生」就是本研究要保留的路徑差異。

不得預設二元的「相似／不相似」距離門檻。距離作為連續量，用於擁擠、最近鄰、邊界及曲線。

## 十九、CVT-MOME 行為空間

### 19.1 為何使用 CVT

二十維特徵若每維各切數格，cell 數會指數爆炸。C 使用 Centroidal Voronoi Tessellation，把可生成行為空間分成 K 個 Voronoi cell。

### 19.2 CVT 校準資料

CVT 中心只能用「符合 C 搜尋邊界的特徵校準合成路徑」建立：

- 不執行參數回測。
- 不使用 `q_rel`、`q_abs`。
- 不依歷史 K 線相似度加權。
- 不從歷史片段複製路徑。

校準路徑使用與正式研究相同的 W、H、邊界及四座標表示。為避免隱藏第二套無上限預算，第一版 CVT 特徵校準路徑數固定等於初始搜尋預算 N；I 必須分開顯示「N 次特徵校準」與「N 次正式回測評估」。

每條校準路徑的正規化 `g、b、u、d` 座標都在 `[0,1]` 內獨立均勻產生。這只是用來覆蓋合法基因空間，不代表歷史或未來行情的機率分佈。

### 19.3 特徵正規化

每項特徵以 CVT 校準路徑的觀測範圍正規化。零範圍特徵定義為 0。

W 與 H 各占整體行為距離一半：

```text
D_feature^2
  = 0.5 * mean((W_feature_a - W_feature_b)^2)
  + 0.5 * mean((H_feature_a - H_feature_b)^2)
```

CVT 中心、特徵正規化範圍、校準 seed、產生器版本及內容 hash 都必須保存並凍結。

### 19.4 K 與 P

初始正式評估預算為 N 時：

```text
K_auto = round(sqrt(N))
P_auto = max(4, round(sqrt(N / K_auto)))
```

- K 是 CVT cell 數。
- P 是每個 cell 的活躍 Pareto 父代容量。
- 使用者可在建立研究前自訂 K 與 P。
- K/P 只限制工作 archive，不限制永久結果保存數量。
- K/P 改變後必須建立新研究。

這些是透明的工程預設，不宣稱為統計最佳值。

## 二十、搜尋覆蓋與多樣性輸出

### 20.1 全域覆蓋

```text
search reach = 搜尋期間曾觸及的 cell 數 / K
A coverage  = 至少有一條 A 路徑的 cell 數 / K
B coverage  = 至少有一條 B 路徑的 cell 數 / K
```

另顯示：

```text
A cell / touched cell
B cell / touched cell
```

### 20.2 必備統計

- 四種結果狀態的評估數。
- 每個 cell 的評估數、A/B 數與活躍 Pareto 數。
- 二十項特徵的 min、p10、median、p90、max。
- 永久唯一路徑數。
- 去重後仍保留的 lineage edge 數。
- 最近鄰 `D_W`、`D_H`、`D_total` 的 min、p10、median、p90。
- 最佳與中位 `q_rel`。
- 最佳與中位 `q_abs`。

純全域隨機失敗可以只保留聚合計數，因此「評估數」可能大於「永久路徑數」。前端必須把兩者分開命名。

不得把上述量壓縮成單一「多樣性總分」。

## 二十一、二維投影與地圖

使用者從二十項特徵中選擇 X 與 Y，查看 CVT 結果的二維投影。

規則：

- 畫面必須標示「二十維行為空間的二維投影」。
- A 與 B 可分開顯示，也可鎖定相同 X/Y 並排比較。
- 二十維中不同 cell 投影後可能重疊；畫面可以聚合顯示，但底層不得合併 cell。
- 色彩一次只表示一項可選指標。

可選色彩至少包括：

- 評估數。
- A 或 B 路徑數。
- 最佳／中位 `q_rel`。
- 最佳／中位 `q_abs`。
- 最近鄰 `D_total`。
- 活躍 Pareto 數。

不得使用 PCA 或 UMAP 作為主要結果圖，也不得讓降維座標取代二十項可解釋特徵。

## 二十二、Anchor 局部邊界分析

使用者選定永久保存的可獲利 anchor 後，查看它的直接子路徑。

### 22.1 散點

提供：

```text
X 軸：D_total、D_W 或 D_H
Y 軸：q_rel 或 q_abs
```

顯示 `q_rel=0`、`q_abs=0` 參考線，並以四種結果狀態著色。

### 22.2 最近觀測失敗

```text
d_fail_A = min(D | anchor 的直接子路徑不符合 A)
d_fail_B = min(D | anchor 的直接子路徑不符合 B)
```

只對 anchor 已通過的目標計算。

若目前沒有觀測到失敗子路徑，顯示「目前樣本中尚未觀測到失敗」，不得顯示無限大，也不得宣稱不存在失敗邊界。

### 22.3 累積觀測通過率

```text
Pass_A(r)
  = 距離 <= r 且符合 A 的直接子路徑數
    / 距離 <= r 的全部直接子路徑數

Pass_B(r)
  = 距離 <= r 且符合 B 的直接子路徑數
    / 距離 <= r 的全部直接子路徑數
```

畫成依實際樣本距離變動的階梯曲線，不建立任意距離分箱。

這是搜尋樣本中的觀測比例，不是市場機率或信賴區間。

### 22.4 篩選與對照

可依下列條件篩選直接子路徑：

- 產生操作。
- W 或 H 變異位置。
- 變異區塊長度。
- 變異幅度。
- 產生 batch。

選定子路徑後，父子 K 線並排顯示：

- 同步 X/Y 軸。
- 標示被修改的 K 線。
- 分開標示 W/H。
- 顯示 `D_W`、`D_H`、`D_total` 與績效差異。

## 二十三、研究任務與續算

### 23.1 任務階層

```text
C 研究
├─ 不可變研究設定
├─ CVT 校準批次
├─ 搜尋批次
├─ 選定 anchor 的鄰域探測批次
└─ 原子生成／特徵／回測任務
```

C 研究是可持續追加的研究容器，不是一個只能執行一次的單次按鈕。

### 23.2 狀態

```text
draft
waiting
running
partially_completed
cancelled
failed
current_plan_completed
```

`current_plan_completed` 只表示目前 manifest 已完成。使用者之後仍可追加預算或鄰域探測。

封存是獨立欄位，不用任務狀態冒充刪除。

### 23.3 三種繼續方式

1. **續跑未完成 batch**
   - 從 checkpoint 與 RNG 位置繼續。
   - 已完成結果不重算。

2. **增加搜尋預算**
   - 沿用相同研究、CVT、K、P、工作集合與 RNG 序列。
   - 原始 K/P 不隨累積預算自動改變。
   - 改 K/P 必須建立新研究。

3. **新增 anchor 鄰域探測**
   - 使用者選定 anchor。
   - 明確設定有限樣本數、操作、尺度、變異 W/H 範圍及幅度。
   - 開始前顯示精確計算量。
   - 直接子路徑依永久保存規則保存。
   - 新成功子路徑可以再成為 anchor。

不同探測 manifest 的通過比例不得靜默混合。畫面必須能分批查看；只有使用者選取相容批次時才可合併統計。

### 23.4 I 契約

每個批次開始前顯示：

- 特徵計算數。
- 新增回測數。
- 預期快取命中數。
- 預估耗時，無法可靠估計時顯示未知。
- 儲存量估計。

執行中顯示：

- 已完成／總數。
- 目前階段。
- 錯誤數。
- 快取命中數。
- 取消。

取消後已完成有效結果保留；未完成批次不得標成完成。

## 二十四、canonicalization、hash 與重現

### 24.1 路徑 canonical

路徑身分使用：

- W/H 長度。
- 交易日期序列。
- 四座標表示版本。
- 依時間與通道固定排序的 `float64` 座標位元。

產生 hash 前：

- `-0` 正規化為 `0`。
- 拒絕 `NaN` 與 `Inf`。
- 不使用前端顯示小數字串作為 hash 輸入。

絕對顯示起始價不進入路徑身分。

### 24.2 評估 key

標準化回測結果 key 至少包含：

- 路徑 hash 與日期。
- 選定參數值 hash。
- H 範圍。
- 起始本金。
- 執行與成本設定。
- 月投入固定為零。
- 回測核心版本。

C study ID、batch ID、cell ID、父代與圖表設定不得塞入底層回測 key。

### 24.3 確定性

同一個：

```text
研究設定
根 seed
搜尋／CVT／變異／RNG 版本
批次 manifest
```

必須產生相同路徑、相同順序、相同 cell 指派及相同結果引用。

連續執行、取消後續算及服務重啟後續算必須一致。軟體版本改變時保留舊研究版本，不得以新版本靜默覆算。

## 二十五、正式資料模型

以下是邏輯模型；實作使用 GORM model 與 AutoMigrate，不建立 SQL migration。

| 模型 | 主要內容 | 不變性／索引 |
|---|---|---|
| `KlineInverseStudy` | 不可變研究設定、來源參數引用、W/H、日曆、成本、邊界、版本、根 seed、狀態、封存 | `study_hash` 唯一 |
| `KlineInverseCalibration` | 校準來源快照、觀測極值、最終邊界、特徵正規化、CVT seed、中心、K/P、內容 hash | 一個 study 一個正式版本 |
| `KlineInverseBatch` | 類型、manifest、預算、RNG 起訖、I 任務引用、狀態、checkpoint | study 內 append-only |
| `KlineInversePath` | canonical 四座標、重建 OHLC、日期、W/H、path hash、永久狀態 | `path_hash` 去重 |
| `KlineInverseEvaluation` | path、標準化回測結果、`q_rel`、`q_abs`、四種狀態、二十項特徵、cell | 實際評估 key 唯一 |
| `KlineInverseLineageEdge` | child、父代、操作、尺度、幅度、變動位置、batch、RNG 位置 | edge 不因 path 去重消失 |

路徑大型 payload 可以分表或物件壓縮保存，但 hash、日期、座標版本、W/H 與血緣不可只存在暫存檔。

永久路徑不得因 archive 父代容量、任務快取清理或前端分頁而刪除。

## 二十六、標準化回測結果整合

每個實際評估引用一筆標準化回測結果：

```text
KlineInverseEvaluation N -> 1 BacktestResult
```

規則：

- C 不另存一份 NAV 真源。
- 生成路徑 hash 作為該次內部合成 dataset 的內容身分。
- 相同路徑、相同參數值及相同回測設定必須重用結果。
- C 的 cell、特徵、父代與 batch 不得降低回測去重率。
- C 路徑是 C 內部研究資料，不自動發布到一般行情資料庫。
- C 結果頁可開啟完整回測結果。
- 回測結果頁可跳回 C study、path 與 evaluation。

## 二十七、G 報酬分析整合

C 的搜尋只需要共用回測摘要中的 `q_rel`、`q_abs` 及必要狀態，不替全部路徑自動建立完整 G 報告。

使用者選定一條永久保存路徑後，可以：

- 開啟既有 G 報告。
- 明確建立新的 G 報告。
- 從 G 跳回 C 路徑。

相同 BacktestResult 與相同 G 設定必須重用報告。切換 cell、anchor、特徵軸或色彩不得觸發 G。

## 二十八、M 與 N 整合

### 28.1 M

M 候選可以建立 C 研究草稿。雙向連結只保存：

- M 候選 ID 與版本。
- C study ID。
- C 任務狀態。
- 已評估數、A coverage、B coverage 等摘要。
- 跳轉位置。

C 不得：

- 修改 M 候選。
- 把 C 指標加入 M 評分。
- 改變 M 候選排序。
- 自動保存或採用參數。
- 把生成 K 線寫入參數庫。

### 28.2 N

C 以精確 study/archive snapshot 作為 N「研究結果比較」來源，提供穩定的唯讀比較資料介面：

- study、archive snapshot、演算法版本與內容 hash。
- 研究設定、所選參數 canonical 來源、W/H、校準邊界與搜尋版本。
- 評估量、A/B 覆蓋率、四種狀態數與缺漏／失敗狀態。
- A/B 地圖、二十項特徵分佈及二維投影。
- 完整路徑距離、多樣性、anchor 與局部失敗邊界統計。
- 永久路徑、血緣、BacktestResult 與既有 G 引用。

完整地圖、特徵資料、路徑與血緣只在 N 展開對應區塊時讀取。N 固定引用 study、archive snapshot、版本與內容 hash；C 追加預算、probe batch 或建立新版 archive snapshot 後，舊 N 工作區不得自動更新。

所選參數若已來自正式參數庫或 M 候選，N 的參數分頁只引用該 canonical 來源；C 只提供 lineage，不重複建立參數項目。

N 不得觸發 C 搜尋、追加預算、建立 probe、修改 C、重算結果、自動評分或合併不相容 CVT 地圖。N 只保存來源引用與顯示狀態，不複製 path、feature、map 或回測 payload。

C 不依賴 N 才能開發完成。

## 三十二、錯誤、併發與恢復

### 32.1 開始前阻擋

下列情況不得開始：

- 未選定參數。
- 無法取得有限 W。
- H、日期或交易日曆無法形成完整 W＋H。
- 校準資料缺少合法 OHLC。
- 來源週期不一致。
- `g、b、u、d` 邊界不合法。
- N、K、P 或 seed 設定不合法。
- plan 已過期或設定 hash 不符。

### 32.2 單條路徑錯誤

下列是計算錯誤，不是「參數不能賺錢」：

- 重建後出現非正價格、`NaN` 或 `Inf`。
- OHLC 順序不合法。
- 實際座標超出凍結邊界。
- 共用回測核心回報錯誤。
- 結果缺少計算 A/B 所需值。

錯誤樣本：

- 不進入 A/B map、覆蓋率或通過比例。
- 保存錯誤類型、batch、RNG 位置與重現資訊。
- 計入任務錯誤數。

合法但虧損或輸給 DCA 的路徑是有效研究結果，不能當錯誤丟棄。

### 32.3 取消與服務重啟

- Checkpoint 只能在完整原子結果提交後前進。
- 路徑、evaluation、血緣與 checkpoint 必須以冪等交易提交。
- 服務重啟後從最後完整 RNG 位置續算。
- 同一 batch 不得同時由兩個 worker 推進。
- 重複訊息只能命中既有結果，不得產生重複預算或血緣遺失。

## 三十三、封存、刪除與備份

- 封存 study 只隱藏於預設列表，不刪除任何結果。
- 有 BacktestResult、G、M 或 N 引用的 study/path 不得直接硬刪。
- 永久路徑及血緣是研究證據，不能由一般快取清理刪除。
- 工作 checkpoint 可依明確保留政策清理，但清理後不得破壞已完成批次與永久結果。
- 備份必須涵蓋 study、calibration、CVT centers、batch、RNG checkpoint、path payload、evaluation、lineage、archive snapshot 與外部引用。
- 還原後必須能繼續尚未完成的相容 batch。

## 三十四、效能與資源控制

- 特徵與距離純計算應批次化，避免逐點資料庫往返。
- 回測 worker 數遵守 I 的資源限制。
- 路徑 payload 壓縮與摘要分離，列表不載入完整陣列。
- 同一 path hash 先去重再回測。
- 相同 BacktestResult 先查快取。
- Cell 聚合、特徵分位與最近鄰統計建立版本化 snapshot，不在每次前端請求掃描全部路徑。
- 最近鄰大量計算可使用精確分批或有版本的索引，但不得悄悄把近似距離冒充精確 `D_total`。
- 所有大量補算都顯示計算量、進度、取消與快取命中。

## 三十五、測試矩陣

### 35.1 路徑數學

- 四座標與 OHLC 雙向轉換。
- 隨機合法座標重建後永遠為正且 OHLC 合法。
- 全部邊界值、零影線、極端跳空及長路徑。
- 反射邊界一次及多次越界。
- 整體價格等比例放大後，座標、特徵與距離不變。
- `-0`、非有限值與 canonical hash。

### 35.2 特徵與距離

- 二十項特徵的手算 fixture。
- 所有零分母規則。
- W/H 完全分離。
- `D(a,a)=0` 與 `D(a,b)=D(b,a)`。
- 只改 W、只改 H、只改單日及只改長區塊的距離。
- 非 2 次方長度的多解析度分區。
- 不同絕對價格基準距離為零。

### 35.3 CVT 與 MOME

- 同 seed 與版本產生相同中心與 cell。
- W/H 特徵各占一半。
- K/P 自動公式及人工值。
- Pareto dominance、極端保留、距離擁擠與固定 tie。
- 五種操作都取得非零配額。
- 父代不足 fallback 可重現。
- A/B 共用評估與 CVT。
- P 淘汰不刪永久路徑。

### 35.4 永久保存與血緣

- 全域隨機成功會成為 anchor。
- 全域隨機失敗只保存聚合與 checkpoint。
- Anchor 直接成功／失敗子路徑都永久保存。
- 失敗子路徑不讓全部後代自動永久化。
- 後代成功時必要祖先鏈升級。
- 路徑去重後所有 lineage edge 仍存在。
- 多父代交叉與 directional variation。

### 35.5 回測語義

- W 無交易、成本、NAV 與現金流。
- H 從固定共同本金開始。
- 參數與 DCA 月投入皆為零。
- DCA 使用同一生成行情。
- C 與回測頁對同一路徑和參數產生相同結果。
- `q_rel`、`q_abs`、A/B 及四種狀態的手算案例。
- 合法虧損結果不被當成錯誤。

### 35.6 任務與恢復

- Plan hash、精確預算及快取命中。
- 不間斷執行與取消續算結果完全一致。
- 服務重啟續算。
- 增加預算延續同一 RNG，不重抽舊樣本。
- K/P 改變必須建立新 study。
- 相容／不相容 probe batch 不被靜默混合。
- 重複訊息與多 worker 競爭的冪等性。

### 35.7 整合與前端

- 四種草稿入口。
- C path、BacktestResult 與 G 雙向跳轉。
- M link 不改評分、排序或採用狀態。
- N 唯讀比較資料介面固定到精確 snapshot 與內容 hash，且不觸發 C 計算。
- A/B 地圖、X/Y、色彩與篩選不觸發回測。
- 大量點位聚合、分頁與完整 path 延遲載入。
- 隱藏頁籤停止重繪。
- 所有內部術語依專案 UI 規則轉為使用者可理解名稱。

## 三十六、端到端驗收情境

至少以一組真實既有參數完成：

1. 從參數庫建立 C 草稿。
2. 選擇日線日曆、H 起始日與 H 長度。
3. 系統自動取得 W。
4. 選擇校準資料並顯示完整觀測邊界。
5. 顯示 CVT 校準與正式回測計算量。
6. 啟動後產生合法 W＋H 路徑。
7. 任務中途取消、重啟服務並續算。
8. 完成目前計畫後看到 A/B coverage、四種狀態、二維投影與二十項特徵。
9. 選定 anchor，追加有限鄰域探測。
10. 看到成功與失敗直接子路徑、最近失敗距離及累積通過率。
11. 並排檢查父子 K 線及修改位置。
12. 開啟其中一條路徑的標準化回測結果與按需 G 報告。
13. 增加搜尋預算，確認舊結果未重算、RNG 延續且永久血緣未丟失。
14. 封存後仍可重開及追溯全部設定、版本與結果。

## 三十七、完成判準

只有下列項目全部成立，C 才能標記為「已完成」：

- 獨立「K 線樣貌反推」頁面與完整建立、任務、結果流程可用。
- W/H、日期、零現金流及 DCA 語義正確。
- 四座標表示、校準邊界與合法重建完整。
- 直接完整路徑、五種操作及 CVT-MOME 搜尋可運作。
- A/B 與四種狀態正確。
- 二十項特徵、完整路徑距離與 CVT 分區正確。
- A/B 地圖、覆蓋率、多樣性統計及 anchor 邊界分析完整。
- 永久保存、工作集合、去重、祖先升級與血緣規則完整。
- I 的計算量、進度、取消、checkpoint、續算及追加預算完整。
- 標準化回測結果、G、M 與 N 邊界依本文件完成。
- 數學、搜尋、回測、恢復、前端與效能測試全部通過。
- 沒有把骨架、展示假資料、少量 hardcode 樣本或單一最佳路徑回報為完成。

## 三十八、禁止的替代實作

不得用下列方式冒充本功能：

- 只做隨機產生 K 線，沒有品質多樣性搜尋。
- 只保留最高報酬路徑。
- 只畫歷史獲利區間。
- 用歷史最近鄰或相似 K 線取代生成搜尋。
- 用單一加權分數合併 `q_rel` 與 `q_abs`。
- 只保存成功路徑，丟掉 anchor 的失敗直接子路徑。
- 用二十維規則格點取代 CVT。
- 用 PCA/UMAP 圖取代可解釋特徵與完整距離。
- 用 DTW 消除事件時間差異。
- 把觀測通過比例宣稱為真實市場成功率。
- 把 C 路徑自動塞入一般行情資料庫。
- 為 C 建立另一套回測、任務或報酬分析核心。
- 讓 C 修改參數、M 評分或參數採用狀態。

## 二十九、使用者可見用詞與二維分布（2026-07-19）

使用者頁面名稱固定為「K 線情境反推」。`W`／`H`、`A`／`B`、anchor、path、cell、lineage、probe、CVT、RNG、`q_rel`、`q_abs` 只保留為內部資料契約或維護文件術語，介面分別使用「前置歷史行情／正式測試行情」、「跑贏定投／跑贏定投且策略正報酬」、「選定成功結果」、「行情結果」、「行情群組」、「這條行情如何生成」、「在選定成功結果附近加強搜尋」、「相對定投優勢／策略總報酬」等文字。

二維分布不得只畫通過 A 或 B 的 cell。前端必須提供「全部已完成結果」、「沒跑贏定投」、「跑贏定投」、「跑贏定投，而且策略正報酬」，預設顯示全部完成結果，並以紅、綠、藍區分失敗、A、B 數量。同一 cell 可同時包含多種結果。二維分布使用 snapshot 的 cell 聚合，因此失敗 evaluation 不需要成為永久 path；永久保存規則仍只適用於既有成功證據，不得為了畫圖改成永久保存所有完整 OHLC。

若沒有永久結果，頁面必須明確顯示「已完成多少條測試、但沒有任何結果跑贏定投」，不得顯示空白圖或誤導使用者去選取不存在的路徑。已有永久結果時自動選取第一筆，完整 OHLC 與生成關係仍按需載入。
