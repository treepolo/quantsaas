# 研究功能使用說明

本說明只涵蓋目前已開放的研究流程：行情資料、研究資料集、回測、參數優化、參數晉升、計算任務與參數穩健性分析。交易、下單、Agent、API Key 設定目前暫停開發，不需要也不應在這個流程中設定。

## 啟動與登入

1. 開啟 `http://localhost:8080`。
2. 註冊或登入帳號。
3. 登入後主畫面會顯示「研究總覽」；側邊欄提供行情資料、行情產生器、研究資料集、市場狀態、優化實驗室、回測、參數穩健性、計算任務與設定。

## 匯入行情資料

1. 進入「行情資料」。
2. 確認交易對為 `BTCUSDT`。
3. 選擇資料週期：
   - `1 天`：適合完整歷史回測與主要參數優化。
   - `1 小時`：適合觀察較細的中短期節奏。
   - `15 分鐘`、`5 分鐘`、`1 分鐘`：資料量較大，建議先用較短日期範圍。
   - `1 秒`：資料量極大，只建議匯入很短範圍。
4. 選擇起始日期與結束日期。
5. 按「匯入」。
6. 下方資料卡會顯示該週期目前筆數、最早資料與最新資料。

行情資料使用 Binance Spot 公開市場資料端點，不需要 API Key，也不會觸發交易。

## 執行回測

1. 先確認「行情資料」中至少有目標週期的資料。
2. 進入「回測」。
3. 選擇資料週期。
4. 選擇參數來源：
   - 使用目前最優參數。
   - 使用指定候選參數。
   - 自訂 JSON。
5. 按「開始回測」。
6. 頁面會顯示總收益率、相對定投優勢、最大回撤、期末權益、淨值曲線與時間段分解。

若尚未匯入該週期資料，回測會提示缺少 K 線資料。

## 執行參數優化

1. 先確認「行情資料」中已有要使用的資料週期。
2. 進入「優化實驗室」。
3. 按「啟動新一輪優化」。
4. 選擇資料週期、族群大小、最大代數與參數繼承方式。
5. 送出任務後，頁面會顯示任務進度。
6. 任務完成後，結果會先成為候選參數。
7. 在「參數庫」中檢查候選參數表現，確認後可晉升為目前最優。

參數優化只產生研究用候選參數，不會自動套用到交易，也不會下單。

## 分析參數穩健性

1. 先準備行情資料，並在「優化實驗室」保留至少一組候選或正式參數。
2. 進入「參數穩健性」，選擇來源參數、標的、週期、日期與執行時點。
3. 選擇研究模式：
   - 一維曲線：檢查單一參數左右格點。
   - 二維格點：檢查兩個參數的 heatmap；完成後可切換成同一批資料的 3D 顯示。
   - 多維稀疏抽樣：在多個參數維度中做固定、可重現的抽樣。
4. 選擇研究軸、格點半徑、多尺度半徑與分析指標，按「預覽計算」。
5. 核對總項目、快取命中與新計算數；若超過軟限制，確認後再建立研究。
6. 建立研究只會固定清單，不會自行開跑；按「開始」後才執行。進度、取消與重試也可在「計算任務」查看。
7. 完成後可切換 Z 軸與疊圖，這些顯示操作不會重跑回測。按「建立正式分析」才會保存新的多尺度、區域、前緣與中心快照。

合格點必須同時滿足期末淨值高於定投基準，且最大回撤小於定投基準。紫色預測點與橘色提案點只供提示，不會參與正式合格、連通區域、前緣或中心判定。

## 目前已知限制

- 交易功能、Agent、API Key、策略實例啟停已從主畫面收起，等你明確要求恢復交易功能時再開發。
- 秒級資料支援匯入，但資料量非常大，請先用短日期範圍測試。
- 目前行情資料以 Binance Spot 公開 K 線為來源。
