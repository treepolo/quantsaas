# 緊急試算工具使用說明

此工具用於主系統、Docker 或資料庫暫時無法使用時，仍能取得 SOXL #21 參數的每日基準模型目標權重。

## 一、匯出備援資料包

主系統與資料庫正常時，先匯出一次資料包：

```powershell
go run ./cmd/emergency-signal export --parameter-id 21 --out emergency/soxl-21.bundle.json
```

如果不是透過目前環境變數連資料庫，可以明確指定 DSN：

```powershell
go run ./cmd/emergency-signal export --parameter-id 21 --dsn "host=127.0.0.1 user=quantsaas password=quantsaas dbname=quantsaas port=5432 sslmode=disable TimeZone=Asia/Taipei" --out emergency/soxl-21.bundle.json
```

`emergency/soxl-21.bundle.json` 內含 #21 參數包與 SOXL 日線資料，不要提交到公開 repo。

## 二、讀取最新結果

已經有備援資料包後，不需要資料庫即可試算：

```powershell
go run ./cmd/emergency-signal latest --bundle emergency/soxl-21.bundle.json
```

工具會輸出：

1. 最新日期與收盤價。
2. 市場狀態。
3. 基準模型目標權重。
4. 前一筆基準模型目標權重。
5. 基準模型目標權重變化。
6. 模型淨值與淨值變化。

同時會產生：

| 檔案 | 用途 |
|---|---|
| `emergency/soxl-21-latest.json` | 機器可讀結果 |
| `emergency/soxl-21-latest.md` | 人類可讀摘要 |

## 三、手動輸入最新收盤價

如果自動資料還沒更新，但已經知道 SOXL 最新收盤價，可以手動輸入：

```powershell
go run ./cmd/emergency-signal calc --bundle emergency/soxl-21.bundle.json --date 2026-06-22 --close 28.34
```

工具會把手動輸入寫到：

```text
emergency/soxl-21-manual-prices.jsonl
```

之後再次執行 `latest`，也會自動套用已輸入的手動收盤價。

## 四、安全注意事項

1. `soxl-21.bundle.json` 是敏感研究成果，預設不提交 GitHub。
2. 此工具不需要交易所 API key，也不會下單。
3. 策略核心仍維持純計算；讀檔、寫檔、資料庫連線只存在命令列外層。
