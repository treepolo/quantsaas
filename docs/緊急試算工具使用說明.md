# 緊急試算工具使用說明

此工具用於主系統、Docker 或資料庫暫時無法使用時，仍能取得 SOXL #21 參數的每日基準模型目標權重。

## 零、你剛剛遇到的錯誤是什麼

如果你直接在 PowerShell 輸入：

```powershell
go run ./cmd/emergency-signal export --parameter-id 21 --out emergency/soxl-21.bundle.json
```

然後看到：

```text
go : The term 'go' is not recognized...
```

這不是你操作錯，也不是工具壞掉，而是因為：

1. 你的 PowerShell 目前位置在 `C:\Users\gg013`，不是專案資料夾 `D:\量化交易`。
2. 你的 Windows 本機沒有安裝 Go，所以不能直接使用 `go run`。

因此平常請優先使用專案根目錄下的 `.bat` 檔。這些 `.bat` 會自動切到專案資料夾，並透過 Docker 裡的 Go 執行工具。

## 快速使用：不用手打 Go 指令

在 `D:\量化交易` 直接雙擊：

| 檔案 | 用途 |
|---|---|
| `匯出SOXL21加密備份到GitHub.bat` | 從資料庫匯出 #21 SOXL 備援資料包，建立加密備份，並推送到 GitHub |
| `上傳SOXL21加密資料包到GitHub.bat` | 與上一個檔案相同，只是名字更直白 |
| `SOXL21查看最新試算.bat` | 用現有備援資料包顯示最新基準模型目標權重 |
| `SOXL21手動輸入收盤價試算.bat` | 手動輸入 SOXL 日期與收盤價，保存資料並重新試算 |

第一次使用時，請先執行 `匯出SOXL21加密備份到GitHub.bat`。

你會被要求設定一組「緊急備援加密密碼」。這組密碼請自己保存好；如果忘記密碼，加密備份就無法解開。

## 一、匯出備援資料包

主系統與資料庫正常時，先匯出一次資料包：

```powershell
go run ./cmd/emergency-signal export --parameter-id 21 --out emergency/soxl-21.bundle.json
```

如果不是透過目前環境變數連資料庫，可以明確指定 DSN：

```powershell
go run ./cmd/emergency-signal export --parameter-id 21 --dsn "host=127.0.0.1 user=quantsaas password=quantsaas dbname=quantsaas port=5432 sslmode=disable TimeZone=Asia/Taipei" --out emergency/soxl-21.bundle.json
```

`emergency/soxl-21.bundle.json` 內含 #21 參數包與 SOXL 日線資料，不要提交到公開 repo。

腳本會另外建立加密檔：

```text
secure-backups/emergency/soxl-21.bundle.json.enc
```

這個 `.enc` 檔可以提交到 GitHub，因為沒有你的加密密碼就無法讀取內容。

## 二、讀取最新結果

已經有備援資料包後，不需要資料庫即可試算：

```powershell
go run ./cmd/emergency-signal latest --bundle emergency/soxl-21.bundle.json
```

工具會輸出：

1. 最新日期與收盤價。
2. 市場狀態。
3. 基準模型目標權重。
4. 前一筆基準模型目標權重。
5. 基準模型目標權重變化。
6. 模型淨值與淨值變化。

同時會產生：

| 檔案 | 用途 |
|---|---|
| `emergency/soxl-21-latest.json` | 機器可讀結果 |
| `emergency/soxl-21-latest.md` | 人類可讀摘要 |

## 三、手動輸入最新收盤價

如果自動資料還沒更新，但已經知道 SOXL 最新收盤價，可以手動輸入：

```powershell
go run ./cmd/emergency-signal calc --bundle emergency/soxl-21.bundle.json --date 2026-06-22 --close 28.34
```

工具會把手動輸入寫到：

```text
emergency/soxl-21-manual-prices.jsonl
```

之後再次執行 `latest`，也會自動套用已輸入的手動收盤價。

## 四、安全注意事項

1. `emergency/soxl-21.bundle.json` 是明文敏感研究成果，預設不提交 GitHub。
2. `secure-backups/emergency/soxl-21.bundle.json.enc` 是加密備份，可以提交到 GitHub。
3. 加密密碼不要放進 GitHub、文件、程式碼或截圖。
4. 此工具不需要交易所 API key，也不會下單。
5. 策略核心仍維持純計算；讀檔、寫檔、資料庫連線只存在命令列外層。
