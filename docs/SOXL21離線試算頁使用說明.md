# SOXL21 離線試算頁使用說明

檔案位置：

```text
SOXL21離線試算.html
```

此檔案是單檔離線頁面。只要瀏覽器能開 HTML，就能匯入 SOXL 加密資料包、手動新增多日收盤價，並試算最新實務模型與基準模型目標權重。`SOXL21` 是沿用的檔名；實際參數 ID 以匯入資料包內容為準。

## 使用流程

1. 開啟 `SOXL21離線試算.html`。
2. 在「加密密碼」輸入你的緊急備援密碼。
3. 選擇 GitHub 上下載的：

```text
secure-backups/emergency/soxl-21.bundle.json.enc
```

4. 按「匯入資料包」。
5. 如果有手動價格備份，也選擇：

```text
secure-backups/emergency/soxl-21-manual-prices.jsonl.enc
```

6. 按「匯入手動價格」。
7. 之後可在頁面裡新增日期與 SOXL 收盤價。

## 資料保存

此頁會把解密後資料保存於目前瀏覽器。若換手機、換瀏覽器、清除瀏覽器資料，就需要重新匯入加密資料包。

手動價格可以從頁面匯出：

1. 「匯出明文紀錄」：只適合本機臨時保存。
2. 「匯出加密紀錄」：適合上傳雲端備份。

## 限制

1. 此頁不會自動抓 Yahoo 或 GitHub 資料。
2. 此頁不會自動推送 GitHub。
3. 此頁的計算邏輯是 Go 緊急試算工具的 JavaScript 鏡像；Go CLI 仍是正式真源。
